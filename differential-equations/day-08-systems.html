Systems of Equations: Matrices, Eigenvalues and Mode Shapes

Real machines have many parts that push on each other: two masses, a gearbox and a motor, coupled tanks, competing populations. Write them as one matrix equation and the eigenvalues and eigenvectors do the rest — giving natural frequencies and mode shapes, the special patterns in which the whole system moves as one.

⏱ about 2–3 hours🧪 Lab: Two-mass mode shapes❓ 5-question quiz

1Today's goals

  • Write coupled equations as x′ = A·x or M·x″ + K·x = 0
  • Revise eigenvalues and eigenvectors of a 2 × 2 matrix
  • Build the general solution as a sum of modes
  • Find natural frequencies and mode shapes from det(K − ω²M) = 0
  • Explain energy exchange, tuned absorbers and why FEA is "just" this with more masses

2Many equations, one matrix

Two masses connected by three springs (wall – k₁ – m₁ – k₂ – m₂ – k₃ – wall). Newton for each mass:

m₁·x₁″ = −k₁x₁ + k₂(x₂ − x₁)
m₂·x₂″ = −k₂(x₂ − x₁) − k₃x₂
Matrix form: M·x″ + K·x = 0, M = [[m₁, 0], [0, m₂]], K = [[k₁ + k₂, −k₂], [−k₂, k₂ + k₃]]

The off-diagonal −k₂ is the coupling: it is why pushing one mass moves the other. First-order systems look the same: two tanks in series, a two-compartment drug model or a predator–prey pair near equilibrium all become x′ = A·x.

3Eigenvalues: directions that do not turn

For a matrix A, an eigenvector v is a direction that A only stretches: A·v = λ·v. The stretch factor λ is the eigenvalue. Find them from

det(A − λI) = 0 → for 2×2: λ² − (trace)·λ + det = 0

Then the general solution of x′ = A·x is a sum of independent pieces, each moving along one eigenvector at its own rate:

x(t) = c₁·eλ₁t·v₁ + c₂·eλ₂t·v₂

The eigenvectors decouple the system: in eigen-coordinates, each equation stands alone. That single idea underlies modal analysis, principal components, Google's PageRank and quantum mechanics.

4Natural frequencies and mode shapes

For M·x″ + K·x = 0 guess x = φ·cos ωt. Then (K − ω²M)·φ = 0, which has a non-zero φ only if

det(K − ω²M) = 0 → n natural frequencies ω₁ < ω₂ < …, each with a mode shape φᵢ

A mode is a pattern in which every part moves at the same frequency, in step (or exactly opposite), with fixed amplitude ratios. Start the system in a mode shape and it stays in it for ever. Any other start is a mix of modes, each ringing at its own frequency — and the mix generally does not repeat.

Orthogonality, and why modes are independent

Because M and K are symmetric, mode shapes are orthogonal with respect to both: φᵢᵀ·M·φⱼ = 0 and φᵢᵀ·K·φⱼ = 0 for i ≠ j. Substituting x = Σ qᵢ(t)·φᵢ and multiplying by φⱼᵀ splits the coupled system into independent single-degree-of-freedom oscillators qⱼ″ + ωⱼ²·qⱼ = (forces projected on φⱼ). With proportional damping each gets its own ζⱼ. Every finite-element vibration analysis does exactly this for millions of degrees of freedom, then keeps only the few modes in the frequency range of interest.

5Worked example

m₁ = m₂ = 1 kg, k₁ = k₃ = 20 N/m, k₂ = 10 N/m (the lab's default)K = [[30, −10], [−10, 30]], M = I det(K − λI) = (30 − λ)² − 100 = 0 → λ = 20 or 40 ω₁ = √20 = 4.47 rad/s, φ₁ = [1, 1] (both move together; the middle spring is never stretched) ω₂ = √40 = 6.32 rad/s, φ₂ = [1, −1] (they move opposite; the middle spring works twice as hard) Pull m₁ by 0.4 only: x(0) = [0.4, 0] = 0.2·φ₁ + 0.2·φ₂ x₁(t) = 0.2·cos 4.47t + 0.2·cos 6.32t, x₂(t) = 0.2·cos 4.47t − 0.2·cos 6.32t → beats: the energy swaps between the masses every π/(6.32 − 4.47) = 1.7 s
Where you meet thisTorsional modes of a motor–coupling–gearbox–dynamometer drive line (keep them away from gear-mesh and running frequencies), building floors, car body and engine-mount modes, the tuned mass absorber (a small spring–mass tuned to the forcing frequency that makes the main mass stand still — used in the Taipei 101 tower and on power-line Stockbridge dampers), molecules' vibration spectra, and coupled pendulum clocks that synchronise.

6Lab: two-mass mode shapes

Start in mode 1 or mode 2 and press P: both masses move at one frequency, in step or opposite. Then choose "pull m₁ only" and reduce the coupling spring k₂: the energy wanders slowly from one mass to the other and back. Make the masses unequal and watch the mode shapes stop being symmetric.

7Pro tips and common mistakes

  • Mode shapes have no absolute size — only ratios matter. Normalise them however you like (largest = 1, or φᵀMφ = 1).
  • A node of a mode (a point that does not move) is the worst place for an accelerometer and the best place for a mounting point.
  • Free–free systems (k₁ = k₃ = 0) have a rigid-body mode at ω = 0 — the whole thing moving together without stretching any spring.
  • Modal testing (an impact hammer and accelerometers) measures ωᵢ, ζᵢ and φᵢ directly; compare with your model's eigen-solution to validate it.

8Practice

  1. Find eigenvalues and eigenvectors of A = [[2, 1], [1, 2]].
  2. For m₁ = 2, m₂ = 1, k₁ = k₂ = k₃ = 10, find both natural frequencies. Check in the lab.
  3. Set k₃ = 0 and k₁ = 0 in the lab. What is mode 1 now?
  4. Write the two-tank system V₁c₁′ = Q(cin − c₁), V₂c₂′ = Q(c₁ − c₂) in matrix form. What are the eigenvalues?
