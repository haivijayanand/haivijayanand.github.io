28-Day Creo Parametric Course · Week 4 · Day 22

Drawings: Templates, Formats and Views

Drawings are still how most parts get made. Learn drawing templates and formats, detail options (.dtl), general, projection, detailed, auxiliary and section views, and first- vs third-angle projection.

⏱ about 2–3 hours🧪 Lab: First vs third angle❓ 5-question quiz

1Today's goals

  • Start a drawing with a template and a format (.frm)
  • Set detail options: projection type, text height, units
  • Place general and projection views, set scale and display style
  • Add detailed, auxiliary, section and broken views
  • Fill the title block from model parameters

2How Creo drawings are built

Drawing (.drw)Views of one or more models, dimensions, notes, tables. Fully associative with the model.
Format (.frm)The border and title block sheet that sits behind. Notes in it can read parameters: &PART_NO, &DESCRIPTION, &todays_date, &scale.
TemplateA drawing that places views automatically when you start a new drawing.
Detail options (.dtl)The drawing's standard: projection_type first_angle, text_height 3.5, drawing_units mm, arrow style, tolerance display. Set through File ▸ Prepare ▸ Drawing Properties ▸ Detail Options.
ViewHow
GeneralThe first view: pick a saved orientation (FRONT, etc.)
ProjectionSelect a view ▸ Projection View ▸ drag right, left, up or down
DetailedPick a point, sketch a spline around it, place the enlarged view
AuxiliaryProjected normal to an inclined edge or datum
SectionView properties ▸ Sections ▸ 2D section (from the model's View Manager)
BrokenView properties ▸ Visible Area ▸ Broken View — long shafts
First angle (ISO, used in India and Europe) puts the left-side view on the right of the front view and the top view below it. Third angle (USA) does the opposite. Same views, different places. Set projection_type once in your company .dtl.

3Do it in Creo

  1. Open your bracket. File ▸ New ▸ Drawing, name bracket, untick default template, Empty with format ▸ browse to an A3 format ▸ OK.
  2. File ▸ Prepare ▸ Drawing Properties ▸ Detail Options: set projection_type first_angle, text_height 3.5. Save the options as company_iso.dtl for reuse.
  3. Layout ▸ General View ▸ click on the sheet ▸ choose FRONT ▸ Scale 1:1 ▸ View Display: No Hidden ▸ OK.
  4. Select it ▸ Layout ▸ Projection View: place a top view below (first angle) and a side view on the right.
  5. Make a cross-section A-A in the part (View Manager ▸ Sections). In the drawing, double-click the side view ▸ Sections ▸ 2D cross-section ▸ A ▸ Full. Add the arrows (right-click the view ▸ Add Arrows).
  6. Layout ▸ Detailed View on a small groove, scale 4:1.
  7. Check the title block: PART_NO and DESCRIPTION from Day 1 fill in by themselves through &parameters in the format.
  8. Change a dimension on the part, return to the drawing — the views update.

4Lab: first vs third angle

Toggle the projection and see where each view lands and which symbol to put in the title block.

5Pro tips and common mistakes

  • Keep company formats and .dtl files in one shared folder and point pro_format_dir and drawing_setup_file there (Day 26).
  • Put the projection symbol and the default tolerance block in the format, linked to parameters.
  • Do not move views by mistake: lock view movement (right-click ▸ Lock View Movement).
  • Show only the views needed to make the part — every extra view is extra checking.
  • Erase Not Displayed before opening a drawing of a model with the same name in another folder.

6Practice

  1. A3 drawing of the bearing housing (Day 11): three views, section A-A through the bore, detail of a tapped hole, first angle, scale 1:2.
  2. A4 drawing of the shaft (Day 5): one broken view, two sections at the keyway and groove.
  3. Make a drawing template that places front, top and right views automatically at 1:1.
