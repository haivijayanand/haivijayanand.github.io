SolidWorks Course Part II · Week 5 · Day 31

DriveWorksXpress and Design Checker

Automate without code. DriveWorksXpress turns a model into a rule-driven product configurator; Design Checker enforces your drafting and modelling standards.

⏱ about 2–3 hours🧪 Lab: Rules engine❓ 5-question quiz

1Today's goals

  • Capture dimensions and features in DriveWorksXpress
  • Build a form and write rules
  • Generate named variants automatically
  • Build and run Design Checker checks

2Rules instead of clicks

DriveWorksXpress (Tools ▸ Xpress Products ▸ DriveWorksXpress, included with SOLIDWORKS) works in four stages:

  1. Capture dimensions, features (suppress/unsuppress) and custom properties of a part or assembly — give each a clear name.
  2. Form: inputs the user fills (numbers, lists, checkboxes).
  3. Rules: Excel-like formulas linking inputs to captured items, e.g. IF(Load>1000,10,8), and a rule for the new file name.
  4. Run: fill the form → DriveWorksXpress creates new, renamed parts, assemblies and drawings.

The full products (DriveWorks Solo / Pro) add web forms, quotes and more — Xpress is the free entry point and good for families of brackets, frames, shafts and plates.

Design Checker

Tools ▸ Design Checker (SOLIDWORKS Professional and Premium) checks documents against standards you define: dimension fonts and arrow styles, allowed materials, units, fully-defined sketches, required custom properties, hole sizes. Build Checks creates a .swstd file — you can learn it from a "golden" document — and Check Active Document lists failures, with automatic corrections for many of them. The Task Scheduler can run it on whole folders.

3Do it in SolidWorks

  1. Model a bracket plate: width, height, thickness, a linear pattern of holes, corner fillets. Name the dimensions (Day 12).
  2. DriveWorksXpress ▸ Capture: width, thickness, fillet radius, hole diameter, pattern count.
  3. Form: inputs Load (number), Width (number), Material (list Steel/Aluminium).
  4. Rules: write the rules from the lab, plus the file-name rule.
  5. Run three variants; open the new files and check names and sizes.
  6. Design Checker: Build Checks — require properties Description, PartNo, Material; require fully defined sketches. Save company.swstd.
  7. Check one of the generated brackets; fix what fails.

4Lab: rules engine

A small configurator with DriveWorksXpress-style rules. Change load, width and material, read which rule fired, and watch the bracket and the generated file name change.

5Pro tips and common mistakes

  • Model the master robustly first — configurators expose every weak sketch.
  • Keep rules readable; put engineering logic (sizes from loads) in a calculation you can show a reviewer.
  • Store generated files in a separate output folder — never overwrite the master.
  • Design Checker is only as good as its rules: start with five checks that catch real mistakes.

6Practice

Configure a shaft: inputs length, bearing seat diameter (list 20/25/30/35), keyway yes/no. Rules: keyway size from the shaft diameter (IS 2048 / DIN 6885 table), chamfer = 1 for ≤ 25 else 1.5, file name SFT-D-L. Generate four shafts and their drawings.
