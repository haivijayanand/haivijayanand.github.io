28-Day SolidWorks Course · Week 2 · Day 08

Reference Geometry: Planes, Axes, Points

When no face is where you need it, make one. Reference planes, axes, points and coordinate systems are invisible scaffolding that hold design intent.

⏱ about 2–3 hours🧪 Lab: 3D reference planes❓ 5-question quiz

1Today's goals

  • Create planes: offset, at angle, mid plane, tangent, normal to curve, through points
  • Create axes and use temporary axes
  • Create reference points and coordinate systems
  • Choose stable references

2The scaffolding

All reference geometry lives under Insert ▸ Reference Geometry (or the Features tab ▸ Reference Geometry drop-down). A plane is defined by up to three references; SolidWorks shows in the PropertyManager whether the plane is fully defined.

Plane typeReferences
Offset distanceA plane or flat face + distance (Flip offset to go the other way; set number of planes for a stack)
At angleA plane/face + an edge or axis (the hinge) + angle
Mid PlaneTwo parallel faces or planes
Parallel through a pointA plane + a vertex or point
Normal to curveAn edge/curve + a point on it — essential for sweep profiles
TangentA cylindrical/conical face + a plane or point
Through 3 pointsThree vertices or points
AxisTwo planes, a cylindrical face, two points, an edge, or a point + face. Or turn on Temporary Axes (View ▸ Hide/Show) — every cylinder already has one.
PointArc centre, face centre, intersection, projection, on edge at distance… Good for mates and measurement.
Coordinate SystemOrigin + axis directions. Used by mass properties, table-driven patterns, export (STEP/STL) and simulation results.
Mate ReferencePre-defines how a part mates (Day 16) — e.g. a bolt "knows" its axis and under-head face.

3Do it in SolidWorks: angled boss

  1. Block 100 × 60 × 40, centred on the origin in X and Z.
  2. Reference Geometry ▸ Plane: first reference the top face, second reference the top-front edge, At angle 35°.
  3. Sketch a Ø30 circle on the new plane, centred on the edge midpoint offset 20 up the plane → Extruded Boss, Blind 25, growing away from the block.
  4. Create a Mid Plane between the left and right faces. Rename it Symmetry.
  5. Show Temporary Axes; create an Axis from the boss's cylindrical face.
  6. Insert a Coordinate System at the top-front-left vertex with X along the long edge — you will use it on Day 14.
  7. Edit the block height to 50 and check that the angled plane, boss and mid plane all follow.

5Pro tips and common mistakes

  • Base planes on the three default planes or main faces, never on fillets or features likely to change.
  • Rename planes (Symmetry, Mounting face, Sweep start) — a tree full of Plane1…Plane9 is unreadable.
  • Hide planes after use (select ▸ Hide) and turn all of them off from the Heads-up View ▸ Hide/Show Items.
  • For a sketch normal to a path at a point, use Normal to curve — exactly what a sweep profile needs.

6Practice: pipe bracket

Base plate 120 × 80 × 10 with four Ø11 holes. A pipe clamp boss (OD 50, ID 34, length 40) whose axis is inclined 30° to the plate, rising from the plate centre. Use an angled plane through a reference axis, then a mid plane to keep the boss centred.
