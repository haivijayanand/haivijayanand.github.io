28-Day Creo Parametric Course · Week 3 · Day 20

Simplified Reps, Exploded Views and Interference

Big assemblies need control. Learn the View Manager: simplified representations, exploded states, cross-sections and combined states; plus Global Interference and clearance checks.

⏱ about 2–3 hours🧪 Lab: 3D exploded view❓ 5-question quiz

1Today's goals

  • Make Master, Geometry, Graphics and Symbolic reps and user simplified reps
  • Create explode states and move components with offset lines
  • Make and show cross-sections
  • Save combined states for drawings
  • Run Global Interference and clearance checks

2The View Manager

View ▸ View Manager (also on the graphics toolbar) holds named states of an assembly:

Simp RepWhich parts are loaded and how: Master (everything), Exclude, Graphics (display only, fast), Geometry (measurable, not editable), Symbolic. Open big assemblies in a light rep.
ExplodePositions of components for an exploded view, with offset lines.
SectionsPlanar, offset (stepped) and zone cross-sections, with hatching for drawings.
Orient / Appearance / AllSaved views, colour states, and combined states (All tab) that bundle a rep + explode + section + orientation + appearance for a drawing view.
Open in a rep. File ▸ Open ▸ the Open button's drop-down ▸ Open Subset / pick a rep. Creo loads only what that rep needs — essential for assemblies of thousands of parts.

Global Interference (Analysis ▸ Global Interference) lists every pair of parts that overlap and the volume. Press fits are expected; anything else is a mistake. Global Clearance finds pairs closer than a set distance.

3Do it in Creo

  1. Open your shaft unit from Day 17. View Manager ▸ Simp Rep ▸ New NO_FASTENERS ▸ Exclude the bolts ▸ OK. Switch between Master and NO_FASTENERS.
  2. Explode tab ▸ New EXP1 ▸ Edit Position: drag the cover up, the bolts up further, the shaft out sideways. Add offset lines from bolt axes to holes.
  3. Sections ▸ New ▸ Planar ▸ through FRONT. Show it; edit the hatch on each part.
  4. All tab ▸ New combined state SECTION_VIEW with Master rep, no explode, section on, saved orientation FRONT.
  5. Analysis ▸ Global Interference ▸ Compute. Explain each pair. Fix any unintended clash.
  6. Save. Close. File ▸ Open the assembly in the NO_FASTENERS rep.

4Lab: exploded view in 3D

Explode a bearing unit — housing, bearing, shaft, cover and screws. Press P to animate.

5Pro tips and common mistakes

  • Make a company standard set of reps for every top assembly: NO_HARDWARE, ENVELOPE, GRAPHICS_ONLY.
  • Envelopes (simple stand-in parts) replace complex bought-out items in large layouts.
  • Explode in assembly order: the order you move things is the fitting order a fitter will read.
  • Name sections A, B, C — those letters appear on drawings.
  • Run interference before every release, and after every change to a mating part.

6Practice

  1. For your gear reducer: reps MASTER, NO_FASTENERS, HOUSING_ONLY; explode EXP_FITTING; section A-A through both shafts; combined state for the GA drawing.
  2. Global Interference: the only interferences should be bearing press fits.
  3. Global Clearance at 2 mm: list parts that come close to the rotating gears.
