The Phase Plane: Linear Systems and the Trace–Determinant Map

Any two-variable linear system x′ = A·x has only a handful of possible pictures: saddles, nodes, spirals and centres. Learn to read them from the eigenvalues, and then from just two numbers — the trace and the determinant — on one map that classifies every 2 × 2 system at once.

⏱ about 2–3 hours🧪 Lab: Matrix phase portrait❓ 5-question quiz

1Today's goals

  • Draw a phase portrait from eigenvalues and eigenvectors
  • Classify the origin as saddle, node, spiral, centre or degenerate
  • Use the trace–determinant map
  • Recognise the spring–mass–damper's three cases on that map
  • Sketch straight-line solutions and the direction of rotation

2The phase plane

For two state variables (x, y), forget time for a moment and draw the vector (x′, y′) at each point of the plane. Solutions are curves that follow the arrows — trajectories or orbits — and the whole set is the phase portrait. Time is still there: it is how fast you move along the curve.

For x′ = A·x the origin is always an equilibrium, and the eigenvalues decide everything.

The direction of rotation of a spiral comes from any one arrow: at (1, 0) the velocity is (a, c); if c > 0 the flow turns anticlockwise.

4The trace–determinant map

The characteristic equation λ² − τ·λ + Δ = 0 depends only on τ = trace = a + d and Δ = det = ad − bc. So one plane with τ across and Δ upwards classifies every 2 × 2 linear system:

Δ < 0 → saddle Δ > 0 and τ² > 4Δ → node Δ > 0 and τ² < 4Δ → spiral
τ < 0 → stable τ > 0 → unstable τ = 0, Δ > 0 → centre
The parabola Δ = τ²/4 separates nodes from spirals.

The oscillator again. x″ + 2ζωn·x′ + ωn²·x = 0 in state form has A = [[0, 1], [−ωn², −2ζωn]], so τ = −2ζωn and Δ = ωn². Increasing damping moves the point left along a horizontal line: centre (ζ = 0) → spiral sink (ζ < 1) → crosses the parabola at ζ = 1 → stable node. Day 5's three cases are three regions of this map.

Structural stability: which pictures survive small changes

Nudge the matrix entries slightly. Saddles, nodes and spirals keep their type — they sit in open regions of the map. Centres (the τ = 0 line), degenerate nodes (on the parabola) and lines of equilibria (Δ = 0) do not: any perturbation changes them. That is why a real "undamped" system always turns out to spiral slightly in or out, and why centres in a linearisation tell you nothing certain about the nonlinear system (Day 10).

5Worked example

x′ = x + y, y′ = 4x − 2y A = [[1, 1], [4, −2]]τ = 1 + (−2) = −1, Δ = (1)(−2) − (1)(4) = −6 < 0 → saddle λ² + λ − 6 = 0 → λ = 2, λ = −3 λ = 2: (1 − 2)·v₁ + v₂ = 0 → v = [1, 1] (outgoing straight line y = x) λ = −3: (1 + 3)·v₁ + v₂ = 0 → v = [1, −4] (incoming straight line y = −4x) Solution: x(t) = c₁·e^(2t)·[1, 1] + c₂·e^(−3t)·[1, −4] Almost every start ends up shooting off along y = x.
Where you meet thisLinearised stability of any operating point: an aircraft's short-period and phugoid modes, a rotor on oil-film bearings (where cross-coupled stiffness can push a spiral sink across into a source — oil whirl), two-species ecology, Romeo-and-Juliet "love dynamics" in Strogatz's famous example, and macro-economic models of inflation and unemployment.

7Pro tips and common mistakes

  • Eigenvectors are lines through the origin, not single arrows — both directions are solutions.
  • Trajectories never cross (uniqueness, Day 1), except at an equilibrium which they approach only as t → ±∞.
  • For real systems you rarely know A exactly; the map tells you how far you are from a boundary — your stability margin.

8Practice

  1. Classify A = [[−2, 1], [−1, −2]] and give the rotation direction.
  2. Classify A = [[3, −2], [4, −1]] using only τ and Δ.
  3. For which k is A = [[0, 1], [−k, −2]] a spiral? A node? Relate to damping.
