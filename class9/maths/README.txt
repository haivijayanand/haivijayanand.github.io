CLASS 9 MATHEMATICS - GANITA MANJARI (NCERT 2026-27)
Revision supplement for students + teaching kit for class teachers. Works fully offline.

HOW TO OPEN
  Unzip the whole folder, then double-click index.html (Chrome, Edge or Firefox).
  No internet is needed. Keep the folder structure as it is.

WHAT IS INSIDE
  index.html            the app (Home, Old->New book map, Worksheet maker, 14 chapters)
  assets/               styles and the engine
  chapters/ch01..ch14   one file per chapter (Part I: 1-8, Part II: 9-14)
  ppt/ChNN_slides.pptx  PowerPoint deck per chapter for class teachers
  formulas.html         one-page formula sheet per chapter (view one or all, print / save PDF)
  Class9_Maths_Formula_Sheets.pdf   all 14 formula sheets, A4, ready to print

EACH CHAPTER HAS FIVE TABS
  1 Revise   one-page summary, formulas, key terms, common mistakes
  2 Explore  interactive figures (drag points, sliders, step-by-step animations)
  3 Practice on-screen questions with new numbers every time + printable worksheets
  4 Check    10-question quiz with explanations (best score is remembered on this PC)
  5 Teach    period-wise lesson plan, misconceptions, activities, exit ticket, slides

KEYBOARD
  M  hide/show sidebar      P  play      S  next step (one per press)      X  pause
  F  full screen            1-5  switch tabs      <- ->  previous/next chapter
  ?  help                   Esc  close slides/help

WORKSHEETS (Practice tab, or "Worksheet maker" for mixed chapters)
  Choose level (Easy / Standard / HOTS), number of questions and a seed.
  Class set: set "roll 1 to 40" -> every student gets different numbers;
  "Print answer key" prints one key for the whole class.
  Every sheet carries a code like C4-L2-N10-S12345. Type it into "Load a sheet code"
  to regenerate exactly that sheet later.

Use alongside the NCERT textbook - this kit summarises and practises, it does not replace it.
