Order Tracking and Run-Up / Coast-Down Analysis

K Vijay Anand · Vijay_Wiki quick-reference article · 24 November 2026
Order trackingRun-upSignal processingResonance

When speed changes, every speed-related component moves across the frequency axis and a normal FFT smears it. Order tracking measures vibration in orders (multiples of running speed) by sampling at fixed shaft angles instead of fixed times. Plotted against speed, order components show which excitation hits which resonance during run-up and coast-down.

Key takeaways

  • Order = frequency ÷ shaft rotation frequency. 1× is unbalance, 2× misalignment, z× gear mesh.
  • Computed order tracking resamples the time signal to equal angle increments using a tachometer or encoder.
  • Order resolution Δo = 1/(number of revolutions analysed); maximum order = samples per revolution ÷ 2.56.
  • In a waterfall or colour map, order lines run diagonally and resonances appear as fixed-frequency bands where order lines brighten.
  • Bode (amplitude and phase versus speed) and polar plots of 1× locate critical speeds: peak amplitude with 90° phase shift.

1. Orders and the angle domain

Order o = f / f_shaft Computed order tracking: tacho → shaft angle θ(t) → resample signal at Δθ = 2π / N_rev_samples Max order = N_rev_samples / 2.56 Order resolution Δo = 1 / revolutions per block

2. Set-up

SettingGuidance
TachometerOnce per rev (optical tape, keyphasor) or encoder for many pulses per rev
Max orderAbove the highest order of interest (e.g. 3–4× gear mesh order for gearboxes)
Revolutions per blockMore revolutions = finer order resolution but more speed change within a block
Run-up rateSlow enough that resonances are excited fully (sweep rate affects peak amplitude)
DisplayWaterfall, colour map (speed vs frequency or order), Bode, polar, order cuts

3. Reading results

  • A component that follows an order line is speed-related; one that stays at fixed frequency is a resonance or external source.
  • Large 1× near a speed with 90° phase change → rotor critical speed.
  • Fixed-frequency bright band crossed by several orders → structural resonance of casing or support.
  • Sub-synchronous components that appear above a threshold speed → instability (e.g. oil whirl).
