01The requirement: make the PC easy enough for the home

In 1993 the PC was still hard to use at home: you started in DOS, typed WIN, juggled CONFIG.SYS for memory, set IRQ jumpers to install a sound card and lived with 8.3 file names. Windows NT was robust but needed expensive hardware and could not run many games. Apple's Mac was easier but costlier. Microsoft's project "Chicago" set out to fix this for the mass market.

Windows 9x (95, 98, ME)

CoreDOS 7/8 boots the machine, then the 32-bit VMM32 takes over
MemoryShared areas mapped into every process — a faulty program could still crash the system
MultitaskingPre-emptive for 32-bit programs; 16-bit programs shared one cooperative queue
FilesVFAT long names; FAT32 from 95 OSR2 (1996)
StrengthCompatibility with games and old hardware; low memory needs

Windows NT family (2000, XP)

CoreThe NT kernel (Episode 06): fully protected, 32-bit
SecurityUser accounts, NTFS permissions — though XP users usually ran as administrators
DriversWindows Driver Model (WDM) shared with 98, which made the merger possible
FilesNTFS with journaling, compression and encryption
StrengthStability: weeks without a reboot instead of hours
Microsoft's long-planned goal was to bring the two families together. Windows 2000 was meant to be that release; consumer compatibility pushed it out to Windows XP.

05The security crisis

Windows was designed for computers that were rarely connected to a network. Always-on broadband changed that. The ILOVEYOU e-mail worm (May 2000) spread through scripts in Outlook; Code Red (2001) hit web servers; Blaster and Sasser (2003–04) infected unprotected XP machines within minutes of going online. In January 2002 Bill Gates's "Trustworthy Computing" memo made security Microsoft's top priority. XP Service Pack 2 (August 2004) turned on the firewall by default, added the Security Center and automatic updates — effectively a new release delivered free.

07Retirement

  • Windows 95: extended support ended 31 December 2001.
  • Windows 98 and ME: extended support ended 11 July 2006 — the end of DOS-based Windows.
  • Windows 2000: extended support ended 13 July 2010.
  • Windows XP: Vista (January 2007) arrived late after a development reset and was disliked, so XP stayed in demand; it was sold on low-cost netbooks until 2010 and support ended on 8 April 2014 — over 12 years after launch. Banks paid for custom support for ATMs still running XP.

08Replacements

XP · 2001→Vista · 2007→Windows 7 · 2009→Windows 8 · 2012→Windows 10 · 2015→Windows 11 · 2021

Dashed boxes mark releases users largely skipped. Windows 7 became "the new XP"; Windows 10 support ended in October 2025, moving users to Windows 11, which requires TPM 2.0 and newer processors.

09Legacy

  • The Start button and taskbar of 1995 remain the centre of Windows 11.
  • Plug and Play and USB made adding hardware ordinary.
  • Monthly security updates ("Patch Tuesday", from 2003) grew out of the XP security crisis.
  • Many industrial test rigs, CNC machines and lab instruments still run XP-era PCs offline, because their drivers and software were never updated.

10Lessons for engineers

  1. Bridges are temporary — plan the exit. Windows 9x was a bridge that took six years to cross.
  2. Designing for a disconnected world fails once it connects. Security must be a default, not an option.
  3. A good-enough product can outlive its successor. XP outlived Vista in the market.
  4. Isolate legacy machines. If an old OS must run a rig, keep it off the internet and document why.
