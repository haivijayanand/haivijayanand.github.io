How to use

  1. Students: read Revise, play with Explore, do 5–10 Practice questions, then take the Check quiz (aim for 9/11).
  2. Teachers: the Teach tab has a period-wise plan; 🎓 Present shows the slides full screen; Practice prints a class set of worksheets with one answer key.
  3. Each worksheet carries a code (for example C4-L2-N10-S12345); type it back in to get the same sheet again.
  4. Unit marks: Relations and Functions 8, Algebra 10, Calculus 35, Vectors and 3-D Geometry 14, Linear Programming 5, Probability 8 (total 80; internal assessment 20).

Use alongside the NCERT textbook — the kit summarises and practises, it does not replace the book.
