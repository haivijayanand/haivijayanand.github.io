CLASS 12 CHEMISTRY - NCERT (NCERT)
Revision supplement for students + teaching kit for class teachers. Works fully offline.

HOW TO OPEN
  Unzip the whole folder, then double-click index.html (Chrome, Edge or Firefox).
  No internet is needed. Keep the folder structure as it is.

WHAT IS INSIDE
  index.html            the app (Home, Worksheet maker, 10 chapters)
  assets/               styles, the engine (core.js) and science widgets (sci.js)
  chapters/ch01..ch10   one file per chapter (same order as the book)
  ppt/ChNN_slides.pptx  PowerPoint deck per chapter for class teachers
  formulas.html         one-page key-ideas sheet per chapter (view one or all, print / save PDF)
  Class12_Chemistry_Key_Ideas_Sheets.pdf   all 10 sheets, A4, ready to print

EACH CHAPTER HAS FIVE TABS
  1 Revise   one-page summary, key ideas, key terms, common mistakes
  2 Explore  interactive panels: sort-it games, step-by-step processes, labelled diagrams, simulations
  3 Practice on-screen questions (fresh numbers where there is a calculation) + printable worksheets
  4 Check    quiz with explanations (best score is remembered on this PC)
  5 Teach    period-wise lesson plan, misconceptions, activities, exit ticket, slides

KEYBOARD
  M  hide/show sidebar      P  play      S  next step (one per press)      X  pause
  F  full screen            1-5  switch tabs      <- ->  previous/next chapter
  ?  help                   Esc  close slides/help

WORKSHEETS (Practice tab, or "Worksheet maker" for mixed chapters)
  Choose level (Easy / Standard / HOTS), number of questions and a seed. Every sheet carries a
  code like C4-L2-N10-S12345; type it into "Load a sheet code" to regenerate that sheet later.

Use alongside the NCERT textbook - this kit summarises and practises, it does not replace it.
