    The big idea

    Creo Parametric (from PTC, the successor of Pro/ENGINEER) is a parametric 3D solid modeller. You build a part out of features — an extrude, a hole, a round — and Creo keeps the recipe in the Model Tree. Pro/ENGINEER invented this way of working in 1988, so many habits you will meet (datums first, strong references, relations) come from there.

    ParametricEvery size is a dimension you can change later. Change 80 to 100 and regenerate (Ctrl+G).
    Feature-basedThe part is a list of features. Each one knows its type, its sketch, its references and its options.
    History-basedFeatures regenerate in tree order. A feature can only reference things that exist above it.
    AssociativePart, assembly and drawing share one database. Change a dimension on the drawing and the part changes.
    ObjectFileWhat it holds
    Part.prtOne component (it can hold several bodies from Creo 7 on)
    Assembly.asmPlacement of parts and sub-assemblies by name — not their geometry
    Drawing.drw2D views, dimensions, notes, tables of a model
    Format.frmBorder and title block that sits under a drawing
    Detail options.dtlDrawing standards: text height, arrows, projection type
    Versions, not overwrites. Every Save writes a new numbered file: bracket.prt.1, bracket.prt.2, bracket.prt.3… The highest number is the latest. Nothing is overwritten, so you can always go back — but folders fill up. File ▸ Manage File ▸ Delete Old Versions keeps only the latest.
    Session memory. Closing a window does not remove the model from memory. If you then open another file called bracket.prt from another folder, Creo shows you the one already in session. File ▸ Manage Session ▸ Erase Not Displayed clears everything not on screen. Do it often.
    The working directory decides where new files are saved and where Creo looks first when it opens an assembly. Forget to set it and your work lands in the start-in folder — the classic first-week loss. Set it every time you start Creo.

    Do it in Creo

    1. Make a folder D:\creo_course\day01. Start Creo Parametric.
    2. Home ▸ Select Working Directory → pick the folder → OK. Check the Folder Browser in the Navigator: it now shows that folder.
    3. File ▸ New → Type Part, Sub-type Solid, name block, untick "Use default template" → OK.
    4. Choose mmns_part_solid_abs (millimetre, newton, second; "abs" = absolute accuracy) → OK. Look at the tree: RIGHT, TOP, FRONT and PRT_CSYS_DEF are already there.
    5. Check units: File ▸ Prepare ▸ Model Properties ▸ Units — it should say millimetre Newton Second.
    6. Navigation drill: middle-drag to spin, Shift + middle-drag to pan, wheel to zoom, Ctrl+D for the standard orientation, Saved Orientations on the graphics toolbar for FRONT, TOP, RIGHT.
    7. Turn datum planes and axes on and off from Datum Display Filters on the graphics toolbar.
    8. Save (Ctrl+S) three times. Look in the Folder Browser: block.prt.1, .2, .3. Then File ▸ Manage File ▸ Delete Old Versions.
    9. Close the window (File ▸ Close), then File ▸ Manage Session ▸ Erase Not Displayed. The model is now out of memory too.
    10. Open File ▸ Options ▸ Configuration Editor and just look: every setting Creo loaded, its value and where it came from. Day 26 covers config.pro properly.

    Weak and strong: the Creo way

    In many CAD systems you can leave a sketch partly free. Creo does not. As you draw, Creo adds dimensions and constraints by itself until the sketch is fully defined. Those automatic dimensions are weak: shown lighter, and Creo will remove them without asking when you add your own. A dimension you add or edit becomes strong and stays.

    Weak dimensionCreo's guess. Lighter colour. Disappears when you add a dimension or constraint that does the same job.
    Strong dimensionYour design intent. Darker. Created when you dimension, or when you change a weak one's value, or right-click ▸ Strong.
    Locked dimensionRight-click ▸ Lock: the value cannot change while you drag geometry. Useful while sketching complex profiles.
    ReferenceA dimension you only want to see, not to drive — shown with "REF". Made by Resolve ▸ Dim > Ref or the Reference tool.
    Sketch references are the edges and datums a sketch measures from. Creo picks two (usually RIGHT and TOP for a sketch on FRONT) when you start; add or change them in Sketch ▸ Setup ▸ References. A sketch dimensioned to good references survives changes; one dimensioned to a random edge breaks when that edge goes.

    A good sketch is simple, closed and intent-driven: only the dimensions a machinist or designer would want, all strong, measured from stable references.

    Do it in Creo

    1. New part sketch_drill (mmns template). Model ▸ Sketch → pick FRONT → Sketch. Creo picks RIGHT as the reference orientation plane.
    2. Click Sketch View on the graphics toolbar so you look straight at the sketch.
    3. Corner Rectangle: click two corners anywhere. Look: Creo has added weak dimensions for width, height and position.
    4. Double-click the width and type 80; double-click the height and type 50. Both become strong. The position dimensions are still weak.
    5. Drag the bottom-left corner onto the intersection of the RIGHT and TOP references until it snaps (a coincident constraint symbol appears). The weak position dimensions vanish — the corner is now constrained instead.
    6. Add a Circle inside, dimension Ø20 and position 25 from the left edge and 25 from the bottom.
    7. Toggle Construction mode (Sketch ▸ Construction Mode) and draw a centreline-like line diagonally. Construction geometry does not become part of the feature.
    8. Try Delete Segment: drag across the top line to trim it into pieces, then Undo.
    9. Turn on Sketch ▸ Inspect: Highlight Open Ends, Overlapping Geometry and Shade Closed Loops. A shaded loop means a valid closed profile.
    10. Click OK (✓). The sketch appears in the tree as Sketch 1. Save.

    Lab: weak vs strong

    A corner rectangle has four degrees of freedom. Tick constraints and dimensions and watch which ones you have captured. Press P to drag the sketch — whatever still moves is held only by weak dimensions.

    Pro tips and common mistakes

    • Do not fight weak dimensions. Just add the dimension you want — Creo removes the weak one it replaces.
    • Before finishing, scan the sketch: no weak dimensions should be left on anything you care about. A weak dimension means "Creo chose this", and Creo may choose differently next time you edit.
    • Use Modify (select several dimensions ▸ Modify) with "Regenerate" unticked to change many values at once without the sketch twisting itself inside out.
    • Sketch roughly to the right size first — huge size changes make the solver flip geometry.
    • Use Project (old name "Use Edge") to reuse model edges, and Offset for walls — both keep a link to the edge.
    • Middle-click ends the current line chain; a second middle-click leaves the tool.

    The nine constraints

    ConstraintSymbolWhat it does
    Vertical / HorizontalV / HLine or two points aligned with the sketch's vertical or horizontal
    Perpendicular⊥Two entities at 90°
    TangentTArc or circle touches a line or arc smoothly
    Mid-pointMPoint at the middle of a line
    Coincident—Points together, point on a line or curve, or two lines collinear, or circle centres together
    Symmetric→←Two points mirror about a centreline
    EqualL1, R1…Equal lengths, radii or curvatures (the subscripts pair them up)
    Parallel//Two lines parallel

    Creo also adds constraints while you sketch when the cursor snaps (you see the symbol appear). Hold Shift to sketch without snapping, or right-click while drawing to disable a proposed constraint.

    Resolve Sketch. If a new dimension or constraint conflicts with existing ones, Creo will not accept an over-constrained sketch. It opens Resolve Sketch, highlights the conflicting items and offers: Undo (drop what you just added), Delete (remove one of the highlighted items), Dim > Ref (turn a dimension into a reference) and Explain (what each one does).

    Constraint or dimension? If the relationship is a rule ("this hole is always in the middle"), use a constraint. If it is a value someone might change ("the hole is 25 from the edge"), use a dimension.

    Do it in Creo

    1. New sketch on FRONT. Draw a centreline (Geometry Centerline) along the vertical RIGHT reference.
    2. Draw an open profile: a horizontal base line, two sloping sides and a top line. Close it.
    3. Click Symmetric, then pick the centreline and the two bottom corners. Repeat for the two top corners.
    4. Pick Horizontal for the top line if it did not snap. Dimension base 80, top 50, height 40.
    5. Add an arc on top, make it Tangent to nothing yet — instead use 3-Point arc between the top corners, then add Equal between the two sloping sides (it is already symmetric — watch what Creo says).
    6. Add a dimension for the angle of one side. Resolve Sketch opens: angle, base, top and height cannot all hold. Choose Dim > Ref on the angle — it now shows the value with REF and drives nothing.
    7. Select the 80, 50 and 40 dimensions ▸ Modify, untick Regenerate, type 100, 60, 45, then OK. The sketch changes once, cleanly.
    8. Right-click the height ▸ Lock. Drag the top arc — the height cannot change. Unlock it again.

    Pro tips and common mistakes

    • Turn constraint display on and off from the graphics toolbar (Sketcher Display Filters) when the sketch gets crowded.

    When you click Model ▸ Extrude the ribbon is replaced by the dashboard: depth option and value, flip arrow, Remove Material, Thicken Sketch, and panels — Placement (the sketch), Options (two-sided depths, taper, capped ends for surfaces), Body Options and Properties (name).

    Revolve basics

    Model ▸ Revolve spins a sketch about an axis. The axis is either a geometry centreline in the sketch (preferred — it lives with the sketch) or an existing datum axis or edge picked in the Placement panel.

    Sketch halfDraw only half the section, on one side of the axis, closed along the axis.
    Diameter dimensionsDimension a point to the centreline, then pick the centreline again and the point again: Creo shows a diameter. Shops read diameters, not radii.
    AngleVariable (typed, default 360°), Symmetric, or To Selected.
    Remove MaterialRevolved cuts make grooves, undercuts and inside profiles.
    Pappus' theorem: volume of a revolved area = area × distance travelled by its centroid = A × 2π·r̄. A quick hand check of mass for any turned part.

    Do it in Creo

    1. New part shaft_d5. Model ▸ Revolve → Define → sketch on FRONT.
    2. Draw a Geometry Centerline (not a construction centreline) along the horizontal TOP reference.
    3. Sketch the stepped half profile above the centreline: Ø30 × 40, Ø40 × 60, Ø25 × 50, closed along the axis.
    4. Dimension diameters (point – centreline – point). Add a 1 × 45° chamfer in the sketch at each end using Chamfer (sketch).
    5. Angle 360°. Finish. Name it SHAFT_BODY.
    6. Revolve again with Remove Material: sketch a 2 × 1.1 groove rectangle on the Ø25 step 5 from its end (a circlip groove), axis = the centreline in that sketch. Finish.
    7. Make a datum axis through the shaft (Model ▸ Axis, pick the cylindrical face). You will use it as a reference for holes and assemblies.
    8. Analysis ▸ Mass Properties → compare the volume with your Pappus estimate.

    Pro tips and common mistakes

    • "Section must be on one side of the axis": a line crosses the centreline. Keep the profile on one side, closed along the axis.

    • Put the turned part's axis on a default datum (TOP/FRONT intersection). Assemblies then use the datum axis, not a random surface.
    • Model chamfers and small radii as separate features if they might change; in the sketch if they are permanent.
    • Pulleys with spokes: revolve the rim and hub, extrude one spoke, then pattern it (Day 7).

    Rounds, chamfers and shells

    RoundModel ▸ Round. Pick edges; each group with one radius is a set. Ctrl-click adds edges to the set. The Sets panel adds new sets, variable radii and conic/curvature-continuous shapes.
    ChamferModel ▸ Chamfer ▸ Edge Chamfer. Schemes D × D, D1 × D2, Angle × D, 45 × D. Corner Chamfer is for vertices.
    ShellModel ▸ Shell. Hollows the part to a thickness; picked surfaces are removed (open). Non-default thickness gives chosen faces another value.
    Auto RoundRounds every edge (or all concave/convex ones) with one radius. Great for castings — put it near the end of the tree.
    Order matters. A good order for a moulded or cast part: base shape → draft → large rounds → shell → ribs and bosses → small rounds. Shell copies the rounds to the inside, so round first if you want rounded inside corners.

    Area removed by a round of radius R at a 90° corner = (1 − π/4)R² ≈ 0.215 R²; by a D1 × D2 chamfer = ½·D1·D2.

    Do it in Creo

    1. New part tray. Extrude a 150 × 100 × 40 block, centred on RIGHT and FRONT.
    2. Round: pick the four vertical edges (Ctrl-click) → R15. One set.
    3. In the same Round, open Sets ▸ New set, pick the bottom edge loop (pick one edge, Shift-click for the chain) → R5. Finish: one Round feature, two sets.
    4. Shell: pick the top face to remove, thickness 3. Open the References panel ▸ Non-default thickness → pick the bottom face → 5. Finish.
    5. Edge Chamfer the top outside edge loop: 45 × D, D = 1.
    6. Try a variable-radius round: on the tray rim, in the Sets panel right-click the radius list ▸ Add radius and set 2 at one end, 6 at the other.
    7. Edit Definition of the first Round and change R15 to R30. Shell follows — the wall stays 3.

    Pro tips and common mistakes

    • Round edges last where possible: rounds are often what breaks when earlier geometry changes (Day 15).
    • Shell fails if a radius on the outside is smaller than the shell thickness — the inside round would have negative radius. Increase the radius or reduce thickness.
    • Use intent edges / surface chains (Shift-pick) so new edges get rounded too when the shape changes.
    • Chamfers on drawings: Creo can show a 45 × D chamfer dimension as "1 × 45°" — set it up in detail options.
    • Do not round every edge in a machined part — every round is a tool change. Rounds on castings, chamfers on machined edges.

    Practice

    1. Model a cast cover: 200 × 120 × 50, R20 vertical corners, R5 bottom edges, shell 4 with the bottom open, flange 10 wide around the open edge (extrude a thin profile).
    2. Add an Auto Round R2 at the end of the tree for all remaining concave edges.

    Pattern types

    TypeDriven byUse for
    DimensionIncrements of the leader's own dimensionsVarying size or position, e.g. holes 10, 20, 30 apart
    DirectionA plane, edge or axis direction + spacingRectangular grids
    AxisRotation about an axis, angle or angular extentBolt circles, spokes, teeth
    FillA sketched region filled with a gridVent holes, perforations
    TableA table of positionsIrregular hole positions
    ReferenceAn existing patternChamfers or threads that follow each patterned hole
    Curve / PointA sketched curve or pointsFeatures along a path, at sketched points
    Pattern leader: the original feature. Change it and every instance updates. To pattern several features together, first Group them (select ▸ right-click ▸ Group) and pattern the group.
    Geometry Pattern copies faces rather than features — useful on imported parts that have no feature history.

    Do it in Creo

    1. Open the plate from Day 4 or make a 200 × 120 × 10 plate. Add a Ø8 hole 20 from RIGHT edge and 20 from FRONT edge (Extrude cut Through All).
    2. Select the hole ▸ Model ▸ Pattern → type Direction. First direction: pick the long edge, 5 instances, 40 apart. Second direction: short edge, 3 instances, 40 apart.
    3. Click a black dot on the preview to skip the middle instance (it turns white). Finish.
    4. Add a 1 × 45° chamfer on the leader hole's top edge. Select the chamfer ▸ Pattern: Creo offers Reference automatically. Finish — every hole gets a chamfer.
    5. New part flange_d7: revolve a flange, add one Ø11 hole on a Ø120 PCD. Pattern ▸ Axis: pick the centre axis, 6 instances, 360° (use "angular extent" to space them evenly).
    6. Edit the pattern count 6 → 8 (double-click the pattern). Spacing updates.
    7. Back on the plate, model one boss on one side of FRONT, then Model ▸ Mirror it about FRONT.

    Pro tips and common mistakes

    • Pattern the hole, not the sketch — and pattern before rounding, so the rounds can be a Reference pattern.
    • For bolt circles, dimension the leader by angle from a datum plane, so the whole circle can be rotated by one number.
    • Large patterns regenerate slowly. In Options, General regeneration checks each instance; Identical is fastest but needs every instance to be the same and not touch edges.
    • Mirror the whole part (select the part name at the top of the tree ▸ Mirror) for left/right handed parts — or use File ▸ Save As ▸ Mirror Part for a separate file.
    • Patterns can drive counts by relations: P12 = floor(LENGTH / 40) (Day 12).
