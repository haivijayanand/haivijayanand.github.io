Antivirus and PC security

Before networks, a virus travelled on floppy disks passed between friends and offices. Then came e-mail worms that circled the world in a day, and finally ransomware that holds hospitals and factories to ransom. Antivirus software grew up in that arms race — from small DOS scanners to the security built into every copy of Windows — with an Indian company, Quick Heal, among the pioneers.

01The requirement: keep unwanted code off the computer

In 1983–84 Fred Cohen, a US graduate student, defined a "computer virus" — a program that copies itself into other programs — and showed that detecting all viruses is mathematically impossible. That result explains everything since: antivirus can only ever be a race, never a guarantee.

02A short history of threats

1971 — Creeper and Reaper. Bob Thomas's experimental Creeper moved between DEC computers on ARPANET printing "I'm the creeper, catch me if you can"; Reaper was written to delete it — arguably the first antivirus.
1982 — Elk Cloner. A 15-year-old's Apple II boot-sector prank spread on floppy disks.
1986 — Brain. Written by the brothers Basit and Amjad Farooq Alvi in Lahore, Pakistan, it infected the boot sector of IBM PC floppies and included their names and address.
1987–1992 — DOS viruses. Jerusalem, Cascade (letters falling down the screen), Stoned; the Michelangelo scare of 6 March 1992 made antivirus a household word.
1988 — Morris worm. The first worm to spread across the Internet, slowing thousands of computers.
1998 — CIH (Chernobyl). Overwrote BIOS chips on some motherboards, making PCs unbootable.
1999–2000 — E-mail worms. Melissa (a Word macro) and ILOVEYOU (a VBScript attachment, from the Philippines) spread through Outlook address books worldwide in days.
2001–2004 — Network worms. Code Red, SQL Slammer, Blaster and Sasser attacked unpatched Windows systems directly — making automatic updates essential.
2010 — Stuxnet. Malware that sabotaged industrial centrifuges through Siemens PLCs, spread partly by USB drives.
2017 — WannaCry and NotPetya. Ransomware using a leaked Windows exploit encrypted computers in hospitals, railways and factories.

04Try it: signatures versus heuristics

A signature scanner matches exact fingerprints (hashes or byte patterns) of known malware: precise, but blind to anything new. A heuristic scanner scores suspicious behaviour: it catches new variants, but can raise false alarms on legitimate tools. Scan the sample folder, then update signatures or change the heuristic threshold.

05Try it: will your backup survive ransomware?

Ransomware encrypts every file it can reach — including backups on connected drives and synced folders. Choose a backup arrangement and see what happens.

06Security in India

  • CERT-In (Indian Computer Emergency Response Team, 2004) issues advisories; since 2022 organisations must report cyber incidents to it within six hours.
  • Cyber Swachhta Kendra (botnet cleaning and malware analysis centre, 2017) offers free bot-removal tools and USB protection utilities.
  • Government offices follow NIC and CERT-In guidelines: approved antivirus, USB control, patching and isolated networks for classified systems.
  • Indian vendors Quick Heal and K7 compete with global brands, including in government and enterprise markets.

08Today: layered defence

  1. Patch Windows and applications promptly — most worms used holes already fixed.
  2. Microsoft Defender with cloud protection and "Controlled folder access" against ransomware.
  3. Least privilege: use a standard account, not administrator, for daily work.
  4. Block unknown USB storage on lab and test PCs; scan media from outside.
  5. Offline and versioned backups — the only certain cure for ransomware.
  6. Be wary of attachments and cracked software — the commonest infection routes.

Free scanners from reputable vendors (Microsoft Safety Scanner, ESET Online Scanner) are useful second opinions. Avoid "PC cleaner" and "driver updater" programs advertised in pop-ups.

09Lessons for engineers

  1. No scanner catches everything. Cohen proved it in 1984; plan for failure.
  2. Test rigs are targets too. Stuxnet showed that isolated industrial PCs can be infected by USB.
  3. Backups must be offline or versioned. A backup the malware can reach is not a backup.
  4. Updates are security. Delaying patches for convenience is the main cause of large outbreaks.
