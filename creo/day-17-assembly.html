Assemblies: Placement and Constraints

Assemblies place parts relative to each other. Learn the Component Placement dashboard, Creo's constraints, the Default constraint, placement status, and how to keep assemblies fast and stable.

⏱ about 2–3 hours🧪 Lab: 3D constraints and DOF❓ 5-question quiz

1Today's goals

  • Start an assembly from the mmns template and place the first part with Default
  • Use Coincident, Distance, Parallel, Angle Offset, Normal, Centered, Tangent and Fix
  • Read the placement status: Fully, Partially, No constraints, Packaged
  • Use the 3D dragger and Move panel
  • Edit, redefine and replace components

2Placement and constraints

Model ▸ Assemble brings in a component and opens the Component Placement dashboard. Each constraint you add removes degrees of freedom; the dashboard shows the status.

ConstraintBetweenTypical use
DefaultComponent csys ↔ assembly csysFirst component — fixed with its datums on the assembly's
CoincidentFaces, planes, axes, points, edgesFaces together; axes aligned (pin in hole)

AutomaticCreo guesses from what you pickFast, but check the result
Status. Fully Constrained: no DOF left. Partially Constrained: some free (you can finish anyway — the part is placed where it is). No Constraints. Packaged: placed without constraints, shown in the tree with a special icon — fine for an early layout, not for release. Over-constraining gives Constraints invalid.

Constraints are stored in the assembly. The part file knows nothing about where it is used.

3Do it in Creo

  1. Set a new working directory. File ▸ New ▸ Assembly ▸ Design, untick default template, choose mmns_asm_design_abs.
  2. Model ▸ Assemble the base plate from Day 15. Choose Default in the constraint list. Status: Fully Constrained. OK.
  3. Assemble a pin (Ø10 × 40 revolve). Pick the pin's axis and the plate hole axis → Coincident. Pick the pin's shoulder face and the plate top → Coincident. Status: Partially Constrained — the pin can still spin. That is correct for a pin.
  4. Assemble a bracket: Coincident bottom face to plate top; Coincident hole axis to pin axis; Parallel side face to plate side face. Fully Constrained.
  5. Edit the bracket's placement (right-click ▸ Edit Definition), change Parallel to Angle Offset 30°.
  6. Use the Move tab or the 3D dragger to drag a partly constrained part and see what is free.
  7. Open the bracket from the tree (right-click ▸ Open), change its thickness, save, return to the assembly and regenerate.

4Lab: constraints and degrees of freedom

Tick constraints and watch which degrees of freedom remain. Press P to drag the bracket.

5Pro tips and common mistakes

  • Place the first component with Default. Every other part then has a stable base.
  • Constrain to datum planes and axes of parts, not to faces of rounds or chamfers — the same reason as in parts.
  • Coincident between two axes is the Creo way of saying "concentric".
  • If something should move (shaft, slide), leave it partially constrained or — better — use a connection (Day 18).
  • Do not over-use Fix: the assembly then stops updating when parts change.
  • Rename components through the assembly (File ▸ Manage File ▸ Rename) so the assembly follows the new name.

6Practice

  1. Assemble a bearing housing (Day 11), a shaft (Day 5) and two bought-out bearings (simple revolves) into a shaft unit. Bearings Coincident axis + face; shaft left free to rotate.
  2. Add four M8 bolts from your Day 13 family table and replace one with a longer instance (right-click ▸ Replace).
  3. Run Analysis ▸ Global Interference and explain each interference reported.
