    How Creo drawings are built

    Drawing (.drw)Views of one or more models, dimensions, notes, tables. Fully associative with the model.
    Format (.frm)The border and title block sheet that sits behind. Notes in it can read parameters: &PART_NO, &DESCRIPTION, &todays_date, &scale.
    TemplateA drawing that places views automatically when you start a new drawing.
    Detail options (.dtl)The drawing's standard: projection_type first_angle, text_height 3.5, drawing_units mm, arrow style, tolerance display. Set through File ▸ Prepare ▸ Drawing Properties ▸ Detail Options.
    ViewHow
    GeneralThe first view: pick a saved orientation (FRONT, etc.)
    ProjectionSelect a view ▸ Projection View ▸ drag right, left, up or down
    DetailedPick a point, sketch a spline around it, place the enlarged view
    AuxiliaryProjected normal to an inclined edge or datum
    SectionView properties ▸ Sections ▸ 2D section (from the model's View Manager)
    BrokenView properties ▸ Visible Area ▸ Broken View — long shafts
    First angle (ISO, used in India and Europe) puts the left-side view on the right of the front view and the top view below it. Third angle (USA) does the opposite. Same views, different places. Set projection_type once in your company .dtl.

    Do it in Creo

    1. Open your bracket. File ▸ New ▸ Drawing, name bracket, untick default template, Empty with format ▸ browse to an A3 format ▸ OK.
    2. File ▸ Prepare ▸ Drawing Properties ▸ Detail Options: set projection_type first_angle, text_height 3.5. Save the options as company_iso.dtl for reuse.
    3. Layout ▸ General View ▸ click on the sheet ▸ choose FRONT ▸ Scale 1:1 ▸ View Display: No Hidden ▸ OK.
    4. Select it ▸ Layout ▸ Projection View: place a top view below (first angle) and a side view on the right.
    5. Make a cross-section A-A in the part (View Manager ▸ Sections). In the drawing, double-click the side view ▸ Sections ▸ 2D cross-section ▸ A ▸ Full. Add the arrows (right-click the view ▸ Add Arrows).
    6. Layout ▸ Detailed View on a small groove, scale 4:1.
    7. Check the title block: PART_NO and DESCRIPTION from Day 1 fill in by themselves through &parameters in the format.
    8. Change a dimension on the part, return to the drawing — the views update.

    Dimensions, tolerances and GD&T

    Show Model AnnotationsAnnotate ▸ Show Model Annotations. Brings the model's own dimensions onto a view. Edit them on the drawing and the model changes — the strongest Creo habit.
    Driven dimensionsAnnotate ▸ Dimension. Measures but does not drive. Use for overall sizes you did not model directly.
    TolerancesTurn on tol_display yes. Each dimension: Nominal, Limits, Plus-Minus, Symmetric, or ISO fit class (H7, g6…) with the Tolerance table.
    Datums and GTOLAnnotate ▸ Datum Feature Symbol marks A, B, C. Annotate ▸ Geometric Tolerance makes the frame. Both can live in the 3D model (MBD) and show on drawings.
    GroupCharacteristicsDatum?
    FormFlatness, straightness, circularity, cylindricityNever
    OrientationParallelism, perpendicularity, angularityAlways
    LocationPosition, concentricity, symmetryUsually
    RunoutCircular runout, total runoutAlways (an axis)
    ProfileLine profile, surface profileOptional
    GD&T Advisor (an extension) checks your scheme as you build it: missing datums, under-constrained features, invalid frames — and Creo 12 extends it to datum reference features and intent surfaces. Without it, the lab below gives the same kind of check for single frames.

    Do it in Creo

    1. Open the bearing housing drawing (Day 22). Select the views ▸ Annotate ▸ Show Model Annotations ▸ Dimensions tab ▸ tick the ones you want ▸ OK.

    Lab: feature control frames

    Build a frame — characteristic, tolerance, modifiers, datums — and the lab checks it is valid.

    Pro tips and common mistakes

    • Show model dimensions; avoid driven ones unless needed. A driven dimension cannot change the part.
    • Datum A is the face the part sits on in use or in the fixture — choose datums from function, not convenience.
    • Flatness never takes a datum. A frame "Flatness 0.05 | A" is invalid.
    • Use Position with Ⓜ for clearance-hole patterns; it gives the shop bonus tolerance.
    • Bearing seats: k6/m6 on shafts, H7 or J7 in housings — and a runout to the shaft axis.

    Practice

    Tables and repeat regions

    A repeat region is a row of a table that Creo copies once for every member of the assembly, filling in report parameters.

    Report parameterShows
    &rpt.indexItem number
    &asm.mbr.nameComponent name
    &asm.mbr.PART_NO, &asm.mbr.DESCRIPTIONYour own model parameters
    &rpt.qtyQuantity
    &rpt.levelIndent level in a multi-level region
    &asm.mbr.typePart or assembly
    Attributes of a repeat region decide its type: Duplicates (one row per instance) vs No Duplicates (one row per part with qty), Flat (only top level) vs Recursive (every level). Recursive + No Duplicates = a parts list for purchase; multi-level with &rpt.level = an indented BOM. Filters drop items like skeletons and bulk items.

    Balloons: Table ▸ Create Balloons uses the repeat region's index numbers, so balloons and BOM always agree.

    Do it in Creo

    1. Drawing of your shaft unit assembly. Table ▸ Table ▸ insert 2 rows × 4 columns at the title block's top edge.
    2. Header row: ITEM, PART NO., DESCRIPTION, QTY.
    3. Table ▸ Repeat Region ▸ Add ▸ Simple ▸ pick the first and last cell of row 2.
    4. Double-click each cell of row 2: Report Symbol ▸ rpt ▸ index; asm ▸ mbr ▸ User Defined ▸ PART_NO; same for DESCRIPTION; rpt ▸ qty.
    5. Table ▸ Update Tables. Rows appear for every component.
    6. Repeat Region ▸ Attributes ▸ No Duplicates + Recursive: a flat parts list with quantities rolled up.
    7. Table ▸ Create Balloons ▸ All. Then Clean up Balloons and drag them to tidy positions.

    Surfaces in Creo

    Surfaces form quilts (one or more joined surfaces). A closed quilt can be solidified; an open one can be thickened or used to cut.

    Boundary BlendModel ▸ Boundary Blend. Curves in the first direction, optional curves in the second. The most-used freeform tool.
    Fill / Merge / TrimFill a flat sketched region. Merge two quilts (intersect or join). Trim a quilt with a curve, plane or other quilt.
    Solidify / ThickenTurn a closed quilt into solid, or replace/cut with it. Thicken gives an open quilt a wall.
    Style (ISDX)Model ▸ Style. Free curves with control points, tied to each other with tangent/curvature conditions; surfaces from them. Freestyle is the sub-division "clay" tool.
    Continuity. G0 = touching (crease). G1 = tangent (no crease, but reflections kink). G2 = curvature-continuous (smooth reflections). In Boundary Blend set each edge's condition: Free, Tangent, Curvature, Normal. Check with Analysis ▸ Inspect Geometry ▸ Curvature (combs) and Reflection (zebra stripes).

    Do it in Creo

    1. New part mouse_shell. Sketch three curves on three parallel datum planes: section arcs of 50, 60, 40 width (front, middle, back). Sketch two side curves on TOP joining their ends.
    2. Model ▸ Boundary Blend: first direction = the three sections; second direction = the two side curves. Finish.
    3. Fill the bottom with a flat sketched region on TOP. Select both quilts ▸ Merge.
    4. Select the merged quilt ▸ Model ▸ Solidify. You have a solid.
    5. Shell it 1.5 with the bottom face removed.
    6. Analysis ▸ Inspect Geometry ▸ Curvature on the top: look at the combs. Then Reflection.
    7. Edit the Boundary Blend ▸ Constraints: set the front edge to Tangent to a planar surface and compare reflections.
    8. Open Model ▸ Style and sketch a free curve with four interpolation points; drag a point and watch the curve.

    Lab: G0 / G1 / G2 combs

    Join two curves with different continuity and watch the curvature comb.

    Pro tips and common mistakes

    • Good surfaces need good curves. Fewer, smoother curves beat many wavy ones.
    • Make the second-direction curves meet the first-direction curves exactly (sketch with Intersect/Project), or the blend fails.
    • Solidify needs a watertight quilt — check with Analysis ▸ Inspect Geometry ▸ Quilt edges (or show quilt edge colours: one-sided edges are open).
    • Reflection stripes that kink at a join mean G1 at best. Curvature boundary conditions fix it.
    • Creo 12 improves advanced surfacing tools; for most mechanical work, Boundary Blend + Fill + Merge + Solidify covers it.

    Practice

    1. A handheld remote case top: boundary blend with curvature-continuous edges, solidified and shelled 1.5.
    2. A fan blade: four section curves along a twisted spine, Boundary Blend, thickened 2.
    3. Show reflection analysis before and after setting curvature boundary conditions; save both images.

    Flexible Modeling

    The Flexible Modeling tab edits geometry directly — faces, not features — while keeping the result as a feature in the tree. Ideal for imported STEP parts and for quick changes to models you do not want to rebuild.

    MoveMove or rotate a set of faces (e.g. a boss) with a dragger or by dimensions; the neighbours stretch to follow.
    Offset / Modify AnalyticOffset faces; change a cylinder's radius or a cone's angle directly.
    RemoveRemove a round, hole or boss from imported geometry.
    RecognitionPattern and symmetry recognition find repeated geometry so one edit changes all instances.

    config.pro

    config.pro is a text file of option value lines. Creo reads it at start-up from the installation's text folder, then the start-in folder, then (for some options) the working directory — later files win. File ▸ Options ▸ Configuration Editor shows every option, its value and its source.

    Mapkeys

    A mapkey is a recorded sequence of commands fired by a short key sequence. File ▸ Options ▸ Environment ▸ Mapkeys Settings (or Tools ▸ Mapkeys in older releases) ▸ New ▸ give keys and a name ▸ Record ▸ do the clicks ▸ Stop ▸ OK ▸ Save Changed. Creo writes them into config.pro.

    Do it in Creo

    1. Import a STEP file (any bracket) with File ▸ Open. On the Flexible Modeling tab, select a boss's faces (Shape Surface set) ▸ Move using Dimensions 10 mm. Finish.
    2. Modify Analytic: pick a hole, change Ø8 → Ø9. Remove: pick a round's face — it is gone.
    3. Close Creo. Make a folder C:\creo_std with sub-folders templates, formats, dtl, materials.
    4. Build your config.pro with the lab below. Save it in your Creo start-in folder (see the desktop shortcut's Properties ▸ Start in).
    5. Restart Creo. File ▸ Options ▸ Configuration Editor: check each option and its source file.
    6. Record a mapkey vf: Saved Orientations ▸ FRONT, then Refit. Stop, OK, Save Changed. Type vf in the graphics window.
    7. Record em: File ▸ Manage Session ▸ Erase Not Displayed ▸ OK.

    Lab: config.pro and mapkey planner

    Tick the options you want, edit the values, and plan your mapkeys. The lab writes a config.pro you can copy and warns about key clashes.

    Pro tips and common mistakes

    • Keep one company config.pro under version control and copy it to every PC; personal mapkeys go in a second file loaded after it.
    • Do not put company options in a working directory's config.pro — they will change behaviour only for some jobs and confuse everyone.
    • Prefix your mapkeys with a letter nobody types in the graphics window (e.g. ; or two letters).
    • Mapkeys that open dialogs can pause for input — tick "Pause" options when recording if a step needs the user.
    • Flexible Modeling on native parts is fine for quick edits, but a feature edit is usually cleaner when the history is good.

    Creo Simulate in one page

    Applications ▸ Simulate switches to Structure (or Thermal). Creo Simulate uses p-elements: instead of a finer mesh, it raises the polynomial order of each element until the answer stops changing — that is convergence.

    1 Material assignmentFrom the part's material (Day 14): E, ν, density, yield.
    2 ConstraintsWhere the part is held. Over-constraining makes it too stiff.
    3 LoadsForce/moment, pressure, bearing load, gravity, temperature.
    4 AnalysisStatic, Modal, Buckling, Fatigue, Prestress. Convergence: Quick Check, Single-Pass Adaptive, Multi-Pass Adaptive.
    5 Run & resultsvon Mises stress, displacement, strain energy. Check the convergence graph.
    6 CheckCompare with a hand calculation; question peaks at corners.
    Singularity: at a perfectly sharp inside corner, a point load or the edge of a fixed constraint the theoretical stress is infinite, so it never converges. Do not design to that number — model the real fillet, spread the load, or read the stress a little away from the point.

    Hand checks for a cantilever of width b, depth h, length L, tip load P: σ = 6PL/(bh²), δ = PL³/(3EI) with I = bh³/12. Creo Simulation Live (the Live Simulation tab) gives instant stress colours while you model — good for direction, not for sign-off.

    Do it in Creo

    1. Model a cantilever 200 × 20 × 10 (L × b × h), material steel.
    2. Applications ▸ Simulate ▸ Structure mode. Material Assignment: check steel is assigned.
    3. Displacement constraint: the 20 × 10 end face, all translations fixed.
    4. Force/Moment load: 300 N downward on the free end face.
    5. Analyses and Studies ▸ New Static ▸ Convergence Multi-Pass Adaptive, polynomial order 1–9, 5 % on displacement and strain energy.
    6. Run. Check the status: converged? at what order? Open Results: von Mises fringe and displacement.
    7. Compare: σ = 6·300·200 / (20·10²) = 180 MPa; δ = 300·200³/(3·210 000·1667) ≈ 2.29 mm.
    8. Put a 300 N point load on a single vertex instead. Run again and watch the stress there not converge — a singularity.

    Pro tips and common mistakes

    • Always read the run status: "did not converge" means the colourful picture is not an answer.
    • Fix the minimum needed. Fixing every face of a bolted joint makes it far too stiff.
    • Use bearing loads on holes and pins rather than a force on half the hole face.
    • Use AutoGEM controls (max element size, isolate for exclusion) to keep elements well shaped at fillets.
    • Factor of safety = yield ÷ peak von Mises (ductile, static). For shafts, fatigue matters more — use the Fatigue Advisor or a hand calculation.
