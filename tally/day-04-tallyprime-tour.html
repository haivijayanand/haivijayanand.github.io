Installing TallyPrime and Finding Your Way

Install TallyPrime, start it in the free Educational mode, and learn the screen: the Gateway of Tally, the top menu, the button bar on the right, Go To (Alt+G) and the keys every Tally user lives by.

⏱ about 2 hours🧪 Lab: Shortcut drill❓ 10-question quiz

1Today's goals

  • Install TallyPrime and open it in Educational mode
  • Know the limits of Educational mode (dates 1, 2 and 31)
  • Find your way round the Gateway, top menu and button bar
  • Use Alt+G (Go To) and Ctrl+G (Switch To)
  • Know the main voucher and navigation shortcuts by heart

2Install and start

  1. Download TallyPrime from the Tally Solutions website and run the installer (Windows, 64-bit). Accept the default folder unless your office has a standard.
  2. Start TallyPrime. On the first screen choose Work in Educational Mode. No licence or sign-in is needed.
  3. You land on the Company screen. On Day 5 you will create Avani Gearworks; for now press Esc to look around.
Educational mode is the full product with one restriction: vouchers can be dated only on the 1st, 2nd and 31st of a month. Every practice entry in this course uses those dates so you can repeat it exactly. Reports, masters and all features work normally. (TallyPrime 7.1 is the release described here; screens move a little between releases.)

Go To (Alt+G) opens any report, master or voucher by typing a few letters — the fastest way to move. Switch To (Ctrl+G) does the same but keeps your place so you can come back.
