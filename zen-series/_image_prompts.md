# Zen Series — image prompts

Make each picture with any image generator, save it under the name shown, and put it in `zen-series/images/`.
The page shows it automatically; until then it shows its built-in ink-wash sketch.
Use the same style prefix every time so the series looks consistent.

**Style prefix:** Traditional Japanese sumi-e ink-wash painting, minimalist. Soft grey washes, lots of empty rice-paper space, a single small red seal stamp in the corner. Serene, quiet mood, 16:10 landscape.
