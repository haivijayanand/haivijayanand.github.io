Getting Started: Interface, Working Directory and Files

What Creo Parametric is, how it stores files, why the working directory is the first thing you set every day, finding your way round the window, and starting every part from the right millimetre template.

⏱ about 2–3 hours🧪 Lab: Explore the Creo window❓ 5-question quiz

1Today's goals

  • Explain "parametric, feature-based, history-based, associative" for Creo
  • Set the working directory and know what it controls
  • Know the file types: .prt, .asm, .drw, .frm and versions like .prt.3
  • Understand session memory: Close, Erase, Erase Not Displayed
  • Rotate, pan, zoom and orient the view without thinking
  • Start every part from the mmns_part_solid_abs template

2The big idea

Creo Parametric (from PTC, the successor of Pro/ENGINEER) is a parametric 3D solid modeller. You build a part out of features — an extrude, a hole, a round — and Creo keeps the recipe in the Model Tree. Pro/ENGINEER invented this way of working in 1988, so many habits you will meet (datums first, strong references, relations) come from there.

ParametricEvery size is a dimension you can change later. Change 80 to 100 and regenerate (Ctrl+G).
Feature-basedThe part is a list of features. Each one knows its type, its sketch, its references and its options.
History-basedFeatures regenerate in tree order. A feature can only reference things that exist above it.
AssociativePart, assembly and drawing share one database. Change a dimension on the drawing and the part changes.
ObjectFileWhat it holds
Part.prtOne component (it can hold several bodies from Creo 7 on)
Assembly.asmPlacement of parts and sub-assemblies by name — not their geometry
Drawing.drw2D views, dimensions, notes, tables of a model
Format.frmBorder and title block that sits under a drawing
Detail options.dtlDrawing standards: text height, arrows, projection type
Versions, not overwrites. Every Save writes a new numbered file: bracket.prt.1, bracket.prt.2, bracket.prt.3… The highest number is the latest. Nothing is overwritten, so you can always go back — but folders fill up. File ▸ Manage File ▸ Delete Old Versions keeps only the latest.
Session memory. Closing a window does not remove the model from memory. If you then open another file called bracket.prt from another folder, Creo shows you the one already in session. File ▸ Manage Session ▸ Erase Not Displayed clears everything not on screen. Do it often.
The working directory decides where new files are saved and where Creo looks first when it opens an assembly. Forget to set it and your work lands in the start-in folder — the classic first-week loss. Set it every time you start Creo.

3Do it in Creo

  1. Make a folder D:\creo_course\day01. Start Creo Parametric.
  2. Home ▸ Select Working Directory → pick the folder → OK. Check the Folder Browser in the Navigator: it now shows that folder.
  3. File ▸ New → Type Part, Sub-type Solid, name block, untick "Use default template" → OK.
  4. Choose mmns_part_solid_abs (millimetre, newton, second; "abs" = absolute accuracy) → OK. Look at the tree: RIGHT, TOP, FRONT and PRT_CSYS_DEF are already there.
  5. Check units: File ▸ Prepare ▸ Model Properties ▸ Units — it should say millimetre Newton Second.
  6. Navigation drill: middle-drag to spin, Shift + middle-drag to pan, wheel to zoom, Ctrl+D for the standard orientation, Saved Orientations on the graphics toolbar for FRONT, TOP, RIGHT.
  7. Turn datum planes and axes on and off from Datum Display Filters on the graphics toolbar.
  8. Save (Ctrl+S) three times. Look in the Folder Browser: block.prt.1, .2, .3. Then File ▸ Manage File ▸ Delete Old Versions.
  9. Close the window (File ▸ Close), then File ▸ Manage Session ▸ Erase Not Displayed. The model is now out of memory too.
  10. Open File ▸ Options ▸ Configuration Editor and just look: every setting Creo loaded, its value and where it came from. Day 26 covers config.pro properly.

5Pro tips and common mistakes

  • Wrong template: a part made with the inlbs template is in inches. If the default template is set wrongly on your PC, fix it with template_solidpart in config.pro (Day 26).
  • Two files with the same name in session is impossible in Creo — names are unique in memory. This is a feature: assemblies find parts by name. Never keep two different shaft.prt files in folders an assembly can see.
  • Rename with File ▸ Manage File ▸ Rename while the assembly is in session — renaming in Windows Explorer breaks every assembly that uses the part.
  • Make one folder per job and set it as the working directory before anything else. A small batch file or desktop shortcut whose "Start in" is the job folder does it automatically.
  • Read the message area. Creo almost always tells you what it is waiting for.

6Practice

  1. Create D:\creo_course with one sub-folder per week. Set the working directory to Week 1.
  2. Make three new parts from the mmns template: plate, shaft, cover. Save, close all windows and Erase Not Displayed. Open each from the Folder Browser.
  3. Add custom parameters to plate: Tools ▸ Parameters → add DESCRIPTION (string), PART_NO (string), DRAWN_BY (string). You will use them on Day 22 to fill the title block.
