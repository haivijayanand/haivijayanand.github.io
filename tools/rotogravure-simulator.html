Rotogravure Register Simulator v2.1

This version models individual web spans, shared live speed, transport distance, tension-induced stretch, progressive cylinder drift, individually switchable camera delay/noise/filtering, register tolerance bands, and substrate waste.

The tension model uses the change from nominal tension, ΔL = ΔT·L/(EA), so steady setup strain is not incorrectly shown as registration error. It is intended for training and sensitivity studies, not machine certification.
