28-Day SolidWorks Course · Week 2 · Day 13

Configurations and Design Tables

One file, many versions. Configurations hold sizes and suppression states; a design table drives them all from an Excel sheet.

⏱ about 2–3 hours🧪 Lab: Design table❓ 5-question quiz

1Today's goals

  • Add configurations and configure dimensions and features
  • Build and edit a design table
  • Use $STATE, $DESCRIPTION, $PARTNUMBER and $PRP parameters
  • Know configurations vs display states

2Configurations

The ConfigurationManager (third tab above the tree) lists configurations. Each can have different dimension values, suppressed or unsuppressed features, materials, custom properties and a part number. Typical uses: bolt lengths, as-cast vs machined, simplified (no fillets) for big assemblies, flat vs formed sheet metal, spring free vs compressed.

  • Right-click a dimension ▸ Configure Dimension → a table of that dimension across all configurations.
  • Right-click a feature ▸ Configure Feature → suppress per configuration.
  • Derived configurations sit under a parent and inherit what they do not override.
  • Display states change only appearance and visibility — they are lighter than configurations. Use them for colours and hidden parts, not for geometry.

Design tables

Insert ▸ Tables ▸ Design Table → Auto-create → choose dimensions. An Excel sheet opens inside SolidWorks: rows = configurations, columns = parameters.

Column headerControls
D1@Sketch1A dimension value
$STATE@Chamfer1S = suppressed, U = unsuppressed
$PARTNUMBERPart number shown in BOMs
$DESCRIPTIONConfiguration description
$PRP@MaterialCustom property value

Microsoft Excel must be installed for embedded design tables.

3Do it in SolidWorks: hex bolt family

  1. Model an M10 × 30 hex bolt: hexagon (Polygon, inscribed) 16 across flats × 6.4 head; shank Ø10 × 30; 1 × 45° chamfer on the end; cosmetic thread.
  2. Rename dimensions: D (shank Ø), L, S, K.
  3. Insert ▸ Tables ▸ Design Table ▸ Auto-create, select D, L, S, K.
  4. Fill rows: M6x20, M8x25, M10x30, M12x40, M16x50 with ISO 4017 head sizes (lab table). Add $STATE@Chamfer1 and $PARTNUMBER.
  5. Click outside Excel. SolidWorks creates the configurations. Double-click each in the ConfigurationManager.
  6. Add a Simplified derived configuration with the cosmetic thread and chamfer suppressed.

4Lab: design table

This table works like the embedded Excel sheet. Click a row to activate a configuration, edit any cell, set the chamfer to S, or add a row.

5Pro tips and common mistakes

  • Plan configurations before modelling: features that only some sizes need should be separate features you can suppress.
  • When editing a dimension with several configurations, the Modify box asks This configuration / All / Specify — read it every time.
  • Too many configurations slow a file. For large families, use separate files driven by the same design table, or Toolbox.
  • Keep the design table as the single source of truth — don't edit configured values by hand afterwards (or set the table to allow model edits to update it).

6Practice

Make a configurable spacer: OD 20/25/30, ID 10.5/13/17, lengths 5, 10, 15 for each — 9 configurations from one design table with part numbers SP-OD-L (e.g. SP-25-10).
