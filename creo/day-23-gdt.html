Dimensions, Tolerances and GD&T

Dimensions and tolerances turn a picture into a contract. Learn to show model dimensions, add driven ones, set tolerance modes, apply ISO fits, and build correct GD&T with datum features and feature control frames.

⏱ about 2–3 hours🧪 Lab: Feature control frames❓ 5-question quiz

1Today's goals

  • Show model annotations instead of re-dimensioning
  • Set tolerance display and modes: nominal, limits, plus-minus, symmetric
  • Apply ISO fits (H7, k6) to dimensions
  • Define datum feature symbols and set datums
  • Write valid feature control frames; know the GD&T Advisor

2Dimensions, tolerances and GD&T

Show Model AnnotationsAnnotate ▸ Show Model Annotations. Brings the model's own dimensions onto a view. Edit them on the drawing and the model changes — the strongest Creo habit.
Driven dimensionsAnnotate ▸ Dimension. Measures but does not drive. Use for overall sizes you did not model directly.
TolerancesTurn on tol_display yes. Each dimension: Nominal, Limits, Plus-Minus, Symmetric, or ISO fit class (H7, g6…) with the Tolerance table.
Datums and GTOLAnnotate ▸ Datum Feature Symbol marks A, B, C. Annotate ▸ Geometric Tolerance makes the frame. Both can live in the 3D model (MBD) and show on drawings.
GroupCharacteristicsDatum?
FormFlatness, straightness, circularity, cylindricityNever
OrientationParallelism, perpendicularity, angularityAlways
LocationPosition, concentricity, symmetryUsually
RunoutCircular runout, total runoutAlways (an axis)
ProfileLine profile, surface profileOptional
GD&T Advisor (an extension) checks your scheme as you build it: missing datums, under-constrained features, invalid frames — and Creo 12 extends it to datum reference features and intent surfaces. Without it, the lab below gives the same kind of check for single frames.

3Do it in Creo

  1. Open the bearing housing drawing (Day 22). Select the views ▸ Annotate ▸ Show Model Annotations ▸ Dimensions tab ▸ tick the ones you want ▸ OK.
  2. Clean up: Annotate ▸ Cleanup Dimensions spaces them; drag the rest. Align with Align Dimensions.
  3. Select the bore Ø47 ▸ Dimension tab ▸ Tolerance ▸ ISO fit ▸ H7. Check the limits shown (47.000 / 47.025).
  4. Annotate ▸ Datum Feature Symbol on the base face → A; on the bore axis → B.
  5. Annotate ▸ Geometric Tolerance: bore axis, Perpendicularity 0.02 to A.
  6. Mounting holes: Position Ø0.2 Ⓜ | A | B. Base face: Flatness 0.05 (no datum).
  7. Add the general tolerance note "ISO 2768-mK" in the title block.

4Lab: feature control frames

Build a frame — characteristic, tolerance, modifiers, datums — and the lab checks it is valid.

5Pro tips and common mistakes

  • Show model dimensions; avoid driven ones unless needed. A driven dimension cannot change the part.
  • Datum A is the face the part sits on in use or in the fixture — choose datums from function, not convenience.
  • Flatness never takes a datum. A frame "Flatness 0.05 | A" is invalid.
  • Use Position with Ⓜ for clearance-hole patterns; it gives the shop bonus tolerance.
  • Bearing seats: k6/m6 on shafts, H7 or J7 in housings — and a runout to the shaft axis.

6Practice

  1. Fully tolerance the shaft drawing: bearing seats Ø25 k6, circlip groove widths, runout 0.02 of seats to datum A-B (common axis of both seats).
  2. Housing: datums A (base), B (bore), C (side face); position of 4 holes to A|B|C.
  3. Check each frame with the lab before you finalise.
