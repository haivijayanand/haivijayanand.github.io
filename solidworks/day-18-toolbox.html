28-Day SolidWorks Course · Week 3 · Day 18

Toolbox, Bearings and Smart Fasteners

Never model a standard bolt again. Toolbox supplies ISO and other standard hardware; Smart Fasteners fills Hole Wizard holes with the right screws automatically.

⏱ about 2–3 hours🧪 Lab: Bolt length❓ 5-question quiz

1Today's goals

  • Activate and use SOLIDWORKS Toolbox
  • Insert bolts, nuts, washers, bearings and pins
  • Use Smart Fasteners with Hole Wizard holes
  • Choose bolt length and thread engagement correctly

2Toolbox and Smart Fasteners

Toolbox is a library of standard parts (ISO, DIN, ANSI, JIS, GB…): bolts and screws, nuts, washers, pins, bearings, retaining rings, keys, gears, structural shapes. Turn it on with Tools ▸ Add-Ins ▸ SOLIDWORKS Toolbox Library (and Toolbox Utilities). Parts are dragged from Task Pane ▸ Design Library ▸ Toolbox.

A Toolbox part is created on demand as a configuration of a master file (or as a copied part, depending on settings in Toolbox Settings). The Toolbox folder is usually shared on the network so everyone uses the same parts and part numbers.

Smart Fasteners (Insert ▸ Smart Fasteners in an assembly) reads Hole Wizard holes and Hole Series and inserts the matching fastener with the length set automatically — with washers and nuts if you add them to the stack.

Bolt length rule of thumb. Through bolt: clamped thickness + washers + nut + at least 2 thread pitches showing. Screw into a tapped hole: engagement about 1 × d in steel, 1.5 × d in cast iron, 2 × d in aluminium, then choose the next standard length; tapped depth should exceed the screw end by about 2 pitches.

3Do it in SolidWorks

  1. Tools ▸ Add-Ins: tick SOLIDWORKS Toolbox Library (Active and Start Up).
  2. Design Library ▸ Toolbox ▸ ISO ▸ Bolts and Screws ▸ Hex Head ▸ Hexagon Bolt ISO 4014 (or 4017). Drag it onto a hole edge — it snaps concentric and coincident.
  3. In the PropertyManager set size M10, length 45, thread display Schematic or Cosmetic.
  4. Add a washer ISO 7089 under the head and a nut ISO 4032 on the other side.
  5. Smart Fasteners: open the Day 11 plate bolted to a base with M8 counterbores. Insert ▸ Smart Fasteners → Populate All. Check the length chosen.
  6. Insert a bearing: Design Library ▸ Toolbox ▸ ISO ▸ Bearings ▸ Ball Bearings ▸ Deep Groove Ball Bearing → 6205 (25 × 52 × 15).
  7. Right-click a Toolbox part ▸ Edit Toolbox Definition to change size later.

4Lab: bolt length

Choose a joint and size; the lab adds up clamp, washers, nut (ISO 4032) and two pitches, then picks the next standard length. Switch to a tapped hole and change the material to see engagement change.

5Pro tips and common mistakes

  • Do not edit Toolbox parts directly — they regenerate. Copy them if you need a special (e.g. a drilled bolt).
  • Set Toolbox to write part numbers and descriptions as custom properties so BOMs (Day 24) are correct automatically.
  • Show threads as cosmetic or simplified in large assemblies — real helical threads are very heavy.
  • Hide all fasteners quickly: right-click the assembly ▸ Hide/Show ▸ Toolbox components (or use a display state).

6Practice

Bolt a 12 mm cover to a 20 mm housing flange with 6 × M8. Through-bolt version with washers and nuts — what length? Tapped-into-cast-iron version — what length and tapped depth? Insert both with Toolbox and compare with the lab.
