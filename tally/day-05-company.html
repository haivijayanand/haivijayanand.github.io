Creating the Company: Features (F11) and Configuration (F12)

Create Avani Gearworks in TallyPrime: company details, financial year, books beginning date, base currency and security — then switch on the right features with F11 and set your working preferences with F12.

⏱ about 2 hours🧪 Lab: Company creation form❓ 10-question quiz

1Today's goals

  • Create a company with the correct state and year dates
  • Understand "financial year beginning" vs "books beginning"
  • Switch on the features a manufacturer needs (F11)
  • Know what F12 Configure changes
  • Know where the company data lives on disk

2Create the company

  1. Press Alt+K → Create.
  2. Fill in the details below. The State decides how GST is split later, so get it right.
  3. Financial year beginning from 1-4-2026; Books beginning from 1-4-2026 (later if you start mid-year — opening balances are as on that date).
  4. Base currency: ₹, INR, show amounts in millions? No (Indian lakh/crore formatting is used).
  5. Press Ctrl+A. TallyPrime offers to set features — say Yes, or press F11 later.
Financial year vs books beginning. The financial year is the accounting period (Indian companies: April–March). Books beginning is the first day you record in TallyPrime. A company that moves to TallyPrime on 1 October starts its books then and enters balances as on that date.

5F12 — Configure

F12 changes how the current screen behaves, not what the company can do. In a voucher it can show more fields (for example, a separate column for batch numbers); in a report, it changes what is shown (for example, detailed vs condensed). Settings stay until you change them.

6Where the data lives

Each company is a numbered folder (like 10000) under TallyPrime's data path (by default inside the installation folder; change it in F1 Help → Settings → Data Location). Back it up with Alt+Y → Backup — never by copying a company that is open.
