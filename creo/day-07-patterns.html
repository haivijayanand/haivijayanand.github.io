28-Day Creo Parametric Course · Week 1 · Day 07

Patterns and Mirror

Patterns copy features so you model once and repeat. Learn Creo's pattern types — Dimension, Direction, Axis, Fill, Table, Reference, Curve, Point — when each is right, and Mirror for symmetric parts.

⏱ about 2–3 hours🧪 Lab: Pattern builder❓ 5-question quiz

1Today's goals

  • Make Direction and Axis patterns with first and second directions
  • Use a Dimension pattern with increments
  • Skip instances by clicking their black dots
  • Use Reference patterns so holes follow their pattern leader
  • Mirror features and whole parts about a datum plane
  • Know Fill, Table, Curve and Point patterns

2Pattern types

TypeDriven byUse for
DimensionIncrements of the leader's own dimensionsVarying size or position, e.g. holes 10, 20, 30 apart
DirectionA plane, edge or axis direction + spacingRectangular grids
AxisRotation about an axis, angle or angular extentBolt circles, spokes, teeth
FillA sketched region filled with a gridVent holes, perforations
TableA table of positionsIrregular hole positions
ReferenceAn existing patternChamfers or threads that follow each patterned hole
Curve / PointA sketched curve or pointsFeatures along a path, at sketched points
Pattern leader: the original feature. Change it and every instance updates. To pattern several features together, first Group them (select ▸ right-click ▸ Group) and pattern the group.
Geometry Pattern copies faces rather than features — useful on imported parts that have no feature history.

3Do it in Creo

  1. Open the plate from Day 4 or make a 200 × 120 × 10 plate. Add a Ø8 hole 20 from RIGHT edge and 20 from FRONT edge (Extrude cut Through All).
  2. Select the hole ▸ Model ▸ Pattern → type Direction. First direction: pick the long edge, 5 instances, 40 apart. Second direction: short edge, 3 instances, 40 apart.
  3. Click a black dot on the preview to skip the middle instance (it turns white). Finish.
  4. Add a 1 × 45° chamfer on the leader hole's top edge. Select the chamfer ▸ Pattern: Creo offers Reference automatically. Finish — every hole gets a chamfer.
  5. New part flange_d7: revolve a flange, add one Ø11 hole on a Ø120 PCD. Pattern ▸ Axis: pick the centre axis, 6 instances, 360° (use "angular extent" to space them evenly).
  6. Edit the pattern count 6 → 8 (double-click the pattern). Spacing updates.
  7. Back on the plate, model one boss on one side of FRONT, then Model ▸ Mirror it about FRONT.

4Lab: pattern builder

Build a rectangular or circular hole pattern, skip instances and watch for overlaps and holes that run off the plate.

5Pro tips and common mistakes

  • Pattern the hole, not the sketch — and pattern before rounding, so the rounds can be a Reference pattern.
  • For bolt circles, dimension the leader by angle from a datum plane, so the whole circle can be rotated by one number.
  • Large patterns regenerate slowly. In Options, General regeneration checks each instance; Identical is fastest but needs every instance to be the same and not touch edges.
  • Mirror the whole part (select the part name at the top of the tree ▸ Mirror) for left/right handed parts — or use File ▸ Save As ▸ Mirror Part for a separate file.
  • Patterns can drive counts by relations: P12 = floor(LENGTH / 40) (Day 12).

6Practice

  1. Perforated cover: 300 × 200 × 2 plate with Ø5 holes on a 10 mm triangular grid inside a sketched R20-corner region, using a Fill pattern. Keep 15 mm clear of the edge.
  2. Spoked handwheel: rim Ø200, hub Ø50, one elliptical spoke, axis-patterned 5 times.
  3. Change the handwheel to 3 spokes with a single edit.
