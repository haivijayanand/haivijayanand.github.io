1. The problem

4,000 drivers travel from Start to End each morning. There are two routes:

  • Top: Start → A on a narrow road taking T/100 minutes (where T is the number of cars on it), then A → End on a wide highway, always 45 minutes.
  • Bottom: Start → B on the wide highway, 45 minutes, then B → End on a narrow road, T/100 minutes.

The city now builds a superb new link from A to B that takes no time at all. Every driver picks the fastest route for themselves. What happens to journey times?

2. The answer

Before the shortcut
65 min
2,000 cars on each route: 2,000/100 + 45 = 65 min.
After the shortcut
80 min
Everyone takes Start → A → B → End: 4,000/100 + 0 + 4,000/100 = 80 min.

Every driver is now 15 minutes slower, and nobody can do better by changing route alone. Closing the shortcut would make everyone faster.

3. Working it out

With the shortcut, the narrow road to A costs at most 4,000/100 = 40 min — always cheaper than the 45-minute highway to B. Likewise B → End (at most 40) beats A → End (45). So for each driver, whatever the others do, the zig-zag is at least as good. Everyone takes it, both narrow roads fill up, and each trip costs 80 min.

This is a Nash equilibrium (also called a Wardrop equilibrium in traffic): no driver can gain by switching alone. It is not the best outcome for the group. Selfish choices and the shared, congestible roads pull apart.

It depends on the traffic

For general N drivers: without the link, time = N/200 + 45. With it, time = N/50 when N ≤ 4,500, then 90 min between 4,500 and 9,000 drivers, then back to N/200 + 45. The link helps below 3,000 drivers and hurts from 3,000 to 9,000.

5. Fine print

  • Dietrich Braess described it in 1968. Real-world examples often cited: closing 42nd Street in New York (1990) and removing Seoul's Cheonggyecheon elevated highway (2003) did not cause the expected jams.
  • The same effect appears in electrical and mechanical networks: adding a link between two springs-and-strings paths can make a weight hang lower — or adding a connection in a power grid can increase line loading.
  • It is a warning for plant layouts too: a new "shortcut" conveyor or shared resource can pull everyone into the same bottleneck.
