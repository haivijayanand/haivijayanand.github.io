30-Day TallyPrime Course · Week 5 · Day 28

Security, Edit Log, Backup and Data Exchange

Keeping the books safe and connected: users and roles, TallyVault encryption, the Edit Log that companies must keep, backup and restore, data repair, migration, exporting and importing (including Excel), printing and sharing.

⏱ about 2 hours🧪 Lab: Flash cards❓ 10-question quiz

1Today's goals

  • Set up users with roles
  • Know what TallyVault and the Edit Log do
  • Back up and restore a company
  • Export reports and import masters and vouchers
  • Share invoices by e-mail and WhatsApp

2Security

  • Users and roles (Alt+K → User Roles / Users and Passwords): the stores clerk can enter receipt notes but not see the Profit & Loss; the accountant can enter vouchers but not alter last month; the owner sees everything.
  • TallyVault (Alt+K → TallyVault): encrypts the company data with a password. If the TallyVault password is lost, the data cannot be recovered — store it safely.
  • Edit Log: companies in India must keep an audit trail of every change to their books (Companies (Accounts) Rules, from 1 April 2023). TallyPrime's Edit Log records each creation, alteration and deletion with user and time; it cannot be switched off once required.

3Data

  • Backup (Alt+Y → Backup): to another drive, daily; keep one copy off the premises or in the cloud (TallyPrime 7 shows the TallyDrive backup status).
  • Restore (Alt+Y → Restore) into a different folder first, check, then use.
  • Repair (Alt+Y → Repair) after a power failure or data error.
  • Migrate old Tally.ERP 9 data to TallyPrime with the migration tool.
  • Export (Alt+E): Excel, PDF, XML, JSON. Import (Alt+O): masters and transactions from Excel or XML — useful for loading 200 stock items at once.
  • Print (Alt+P) and share (Alt+M) by e-mail; send invoices and reminders on WhatsApp from TallyPrime.
