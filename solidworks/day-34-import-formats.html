SolidWorks Course Part II · Week 5 · Day 34

Import, Repair and File Formats

Most of your suppliers and customers do not use SolidWorks. Choose the right neutral format, import cleanly, repair what breaks and get features back when you need them.

⏱ about 2–3 hours🧪 Lab: Format chooser❓ 5-question quiz

1Today's goals

  • Choose between Parasolid, STEP AP203/214/242, IGES, STL/3MF, DXF
  • Import with Import Diagnostics and repair faces
  • Recognise features with FeatureWorks
  • Use 3D Interconnect for native files

2Formats and what they carry

Neutral formats carry geometry, not the feature tree. An imported part is a "dumb solid" (an Imported1 feature) that you can still cut, fillet and measure — but not edit by its original dimensions.

  • Export: File ▸ Save As → choose the type; set options in System Options ▸ Export (STEP protocol, units, output as solid/surfaces, coordinate system).
  • Import: File ▸ Open the STEP/IGES/Parasolid; options under System Options ▸ Import.
  • Import Diagnostics (Tools ▸ Evaluate ▸ Import Diagnostics) finds faulty faces and gaps, and can heal them; then Knit surfaces into a solid if needed.
  • FeatureWorks (add-in) — right-click Imported1 ▸ FeatureWorks ▸ Recognize Features: automatic or interactive recognition of extrudes, revolves, holes, fillets, chamfers.
  • 3D Interconnect opens native files from other CAD systems directly and keeps a link: Update when the original changes; Break Link to make it independent.
  • Direct editing of dumb solids: Move Face, Delete Face, Replace Face (Day 26).

3Do it in SolidWorks

  1. Export the pillow block as STEP AP214 and as Parasolid. Open both; compare tree, colours and file size.
  2. Download a supplier STEP of a motor or bearing (any vendor site). Open it; run Import Diagnostics.
  3. If faces are listed as faulty, Attempt to Heal All; check with Tools ▸ Evaluate ▸ Check.
  4. Activate FeatureWorks (Tools ▸ Add-Ins); Recognize Features on a simple imported part; edit a recognised hole.
  5. Export a sheet-metal flat pattern to DXF (Day 21) and open it in eDrawings to check the layers.
  6. Save an STL for 3D printing: Options → resolution Fine; check deviation and angle.

5Pro tips and common mistakes

  • Agree the format and units with the supplier; send STEP AP214 by default, Parasolid to Parasolid-based systems.
  • Large imported assemblies: import as a multibody part if you only need an envelope.
  • Check mass and a few key dimensions after import — tolerance mismatches can leave tiny gaps.
  • Do not send native files to outsiders unless agreed — they contain your full design history.

6Practice

Import a STEP of a commercial gear motor, defeature it to an envelope, add mate references at its mounting face and shaft axis, and save it as your library part.
