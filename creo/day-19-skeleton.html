Top-Down Design: Skeletons, Copy and Publish Geometry

Top-down design starts from a skeleton: a light part that holds the layout — shaft centres, envelopes, interfaces. Learn skeleton models, Copy Geometry and Publish Geometry, and how to keep external references under control.

⏱ about 2–3 hours🧪 Lab: Skeleton-driven parts❓ 5-question quiz

1Today's goals

  • Create a skeleton model in an assembly
  • Put layout datums, curves and surfaces in the skeleton
  • Pass geometry to parts with Copy Geometry and Publish Geometry
  • Control dependency and external references
  • Know when top-down pays off

2Skeletons

A skeleton model is a special part in an assembly (Model ▸ Create ▸ Skeleton Model). It sits at the top of the tree, has no mass, is left out of BOMs, and holds the layout: datum axes for shafts, planes for joint faces, curves for paths, surfaces for envelopes.

Publish GeometryIn the skeleton: a named package of references ("GEARBOX_INTERFACE") so parts take exactly that set and nothing else.
Copy GeometryIn each part: copies references (or a published package) from the skeleton. The part's features are built on the copies — local references.
DependentCopy Geometry can stay dependent (updates when the skeleton changes) or be made independent (frozen).
Reference ControlModel ▸ Reference Control (or in config.pro) limits which external references are allowed — e.g. only to skeletons.
Why not just sketch in context? A part that references other parts' faces directly breaks when they change and drags all of them into memory. Referencing one skeleton through Copy Geometry gives one clear source of truth and a part that opens on its own.

3Do it in Creo

  1. New assembly reducer. Model ▸ Create ▸ Type Skeleton Model ▸ name reducer_skel ▸ Copy from existing (empty mmns part). Place it with Default.
  2. Activate the skeleton (right-click ▸ Activate). Add datum axes A_IN and A_OUT 59 apart, a plane JOINT_FACE, and a sketched envelope curve for the housing.
  3. Name the centre distance C in the skeleton. Model ▸ Publish Geometry: A_IN, A_OUT, JOINT_FACE → name LAYOUT.
  4. Activate the assembly again. Create a part housing (Model ▸ Create ▸ Part ▸ Solid, empty mmns). Activate it.
  5. Model ▸ Get Data ▸ Copy Geometry ▸ Publish geometry ▸ pick LAYOUT. Finish. Build the housing bores on the copied axes.
  6. Do the same for the cover. Activate the assembly.
  7. Change C in the skeleton from 59 to 70. Regenerate the assembly — housing and cover bores move together.

4Lab: skeleton-driven parts

Move the skeleton's centre distance and bearing size and see which design approach keeps the parts matching.

5Pro tips and common mistakes

  • Keep skeletons light: datums, curves and simple surfaces. No solid features.
  • Name everything in the skeleton; parts will show those names in Copy Geometry.
  • Use Publish Geometry for anything more than one or two references — it documents the interface.
  • Information ▸ Reference Viewer on a part shows its external references; anything not going to the skeleton is a warning sign.
  • Top-down pays off on products with many interacting parts that change together — gearboxes, frames, housings with covers. For a single bracket it is overkill.

6Practice

  1. Build the gear reducer skeleton: shaft axes, bearing planes, joint face, bolt-pattern points, envelope surface.
  2. Housing and cover take geometry only from published packages. Bolt holes in both come from the same skeleton points.
  3. Change the bolt PCD and C in the skeleton; check holes still line up with Global Interference on bolts.
