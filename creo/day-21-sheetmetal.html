Sheetmetal: Walls, Bends, Y-Factor and Flat State

Sheet metal is designed bent and manufactured flat. Learn the Creo Sheetmetal application: walls, flanges, bends, reliefs, Y-factor and K-factor, bend tables, flat state and flat pattern preview.

⏱ about 2–3 hours🧪 Lab: Flat length + Y-factor❓ 5-question quiz

1Today's goals

  • Start a sheetmetal part and set thickness and bend allowance
  • Make planar, flat and flange walls with reliefs
  • Understand Y-factor = K·π/2 and bend allowance
  • Unbend, bend back and create a flat state
  • Convert a solid to sheetmetal

2Sheetmetal in Creo

File ▸ New ▸ Part ▸ Sheetmetal (template mmns_part_sheetmetal_abs). The whole part has one thickness; every wall knows how to unbend.

Planar wallThe first flat wall from a closed sketch.
Flat wallAttached to an edge, flat shape from a library (rectangle, trapezoid, user sketch) at an angle.
Flange wallProfile along an edge or chain (I, L, J, S, hem, open…). The workhorse.
Bend / Unbend / Bend BackBend a flat region on a line; unbend for flat work; bend back after.
ReliefsBend relief (rip, stretch, rectangle, obround) and corner relief stop tearing.
Flat PatternA feature that shows the part flat; Flat Pattern Preview shows it in a separate window.
Y-factor vs K-factor. Creo uses the Y-factor by default: Y = K·π/2. Bend allowance BA = (π/2·R + Y·T)·θ/90° for angle θ. Default Y = 0.50 means K ≈ 0.32. Many companies use bend tables instead (measured values per material/thickness/radius). Set it in File ▸ Prepare ▸ Model Properties ▸ Bend Allowance.

3Do it in Creo

  1. New Sheetmetal part bracket_sm.
  2. Planar wall: sketch 100 × 60 on TOP, thickness 2 in the dashboard (this sets the thickness of the whole part). Finish.
  3. Flange wall on one long edge: I-type, height 40, angle 90°, inside radius 2. Relief: Rip.
  4. Flange on the opposite edge: L-type (flange with a return of 15).
  5. Cut two Ø9 holes with an extrude Sheetmetal cut (normal to the sheet).
  6. Check bend allowance: File ▸ Prepare ▸ Model Properties ▸ Bend Allowance — note Y-factor 0.5. Change it to K 0.44 (Y 0.69) and watch the flat length change.
  7. Flat Pattern: pick the base wall as the fixed geometry. Measure the flat length; compare with the lab.
  8. Convert a solid: open a shelled box from Day 6, Operations ▸ Convert to Sheetmetal → Shell, add Edge rips at the corners.

4Lab: flat length and Y-factor

Thickness, radius, angle, K and flange lengths → bend allowance, bend deduction, flat length, and the Y-factor Creo would use.

5Pro tips and common mistakes

  • Agree Y/K or bend tables with the shop. A wrong factor makes every flat pattern slightly wrong — enough to make flanges miss holes.
  • Keep holes at least 2T + R from a bend edge or they stretch into ovals.
  • Use Flat Pattern as the last feature; Unbend/Bend Back in the middle of the tree only for features that must be cut flat across a bend.
  • Minimum flange height ≈ 2.5T + R so the press-brake die can grip it.
  • Drawings of sheetmetal parts: one sheet with the bent views and a flat state view with bend lines and bend notes.

6Practice

  1. Electrical enclosure lid 300 × 200 × 2, four 25 flanges with 3 mm corner reliefs, louvres in the top (Form or Punch from a library if you have one, or simple slots).
  2. Z-bracket 2.5 thick: 40 – 60 – 40 with two 90° bends, R 2.5. Check the flat length with the lab.
  3. Make a bend table or Y-factor change for aluminium 5052 (K ≈ 0.40) and compare the flat lengths.
