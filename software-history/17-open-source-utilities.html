Utilities: 7-Zip, KeePass, PowerToys and more

Every Windows PC collects small utilities: something to open archives, something to keep passwords, something to make a bootable USB stick, take screenshots, or see what is filling the disk. For many of these jobs the best-known tools are open source — often written by a single developer — and Microsoft itself now publishes some of its utilities as open source.

027-Zip and the archivers

On DOS, Phil Katz's PKZIP (1989) made the ZIP format universal, and WinZip (1991) gave it a Windows face. Eugene Roshal's RAR (1993) and WinRAR (1995) compressed better and split archives across floppies. Both were shareware.

In 1999 the Russian programmer Igor Pavlov released 7-Zip, free and open source (LGPL, with a restriction on its RAR-decompression code). His LZMA method used a much larger dictionary than ZIP's Deflate and usually produced noticeably smaller archives; the .7z format and LZMA were later used inside Linux packages, installers and firmware. 7-Zip remains essentially a one-person project with a plain interface, and it now opens almost every archive format.

  • Mark of the Web: Windows tags downloaded files so it can warn before running them. 7-Zip passes this tag to extracted files since version 22.00 (2022), but nested archives escaped it. The flaw CVE-2025-0411 was fixed in 24.09; it was exploited in real attacks and added to CISA's Known Exploited Vulnerabilities list. 7-Zip has no automatic updater, so users must update manually.
  • Relatives: PeaZip (Giorgio Tani, 2006) adds a richer interface on 7-Zip's engine; NanaZip (2021) is a 7-Zip fork packaged for the Microsoft Store and the Windows 11 right-click menu.
  • Windows catches up: since late 2023 Windows 11 can open 7z, RAR and TAR files itself, using the open-source libarchive library.

03Try it: how compression finds repetition

Compressors replace repeated text with short references back to earlier text (the LZ77 idea), then use shorter codes for common symbols. Data-acquisition logs with repeating channel names and similar numbers compress very well; random data does not. This demo uses your browser's built-in Deflate — the method inside ZIP and PNG.

04KeePass and password managers

KeePass was released by the German developer Dominik Reichl in 2003 under the GPL. It stores all passwords in one encrypted database file (.kdbx), opened with a master password and optionally a key file; nothing is sent to a cloud unless you put the file there yourself. KeePass 2.x (2007) moved to .NET with plugins. KeePassXC (2016) is a cross-platform community rewrite that reads the same files, and many phone apps do too.

Because KeePass is open source, criminals in 2024–2025 rebuilt it with hidden code — "KeeLoader" — signed it with valid certificates, and promoted it through Bing and DuckDuckGo search adverts leading to look-alike domains. The fake program worked normally while exporting the password database and installing a Cobalt Strike backdoor; it was found during a ransomware investigation in February 2025. The real KeePass was never compromised — the attack depended entirely on users downloading from the wrong site.

06Microsoft's own open-source utilities

The original PowerToys were unofficial add-ons for Windows 95 and XP (TweakUI, ClearType Tuner). In 2019 Microsoft relaunched PowerToys for Windows 10/11 as an open-source project on GitHub (MIT licence), with community contributions: FancyZones window layouts, PowerRename, Image Resizer, Color Picker, Always on Top, Text Extractor (OCR), Keyboard Manager, and a command launcher. In the same year, at Build 2019, it announced Windows Terminal — tabs, GPU text rendering, full Unicode and profiles for PowerShell, Command Prompt and WSL — also open source; it became the default terminal in Windows 11. In 2025 Microsoft open-sourced WSL itself (Episode 20).

Microsoft's attitude changed sharply: in 2001 its CEO called Linux "a cancer"; by 2018 it had bought GitHub, the largest home of open-source code.

10Lessons for engineers

  1. One skilled developer can serve hundreds of millions. 7-Zip, Rufus and KeePass each began as one person's project.
  2. Know your data before choosing a method. Repetitive logs compress tenfold; already-compressed video does not.
  3. Open source helps attackers copy as well as users inspect. The defence is the download source and signatures.
  4. Keep secrets local where you can. An encrypted file you control limits the damage of someone else's breach.
