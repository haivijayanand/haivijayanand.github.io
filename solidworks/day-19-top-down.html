Top-Down Design: In-Context, Layouts and Skeletons

Design parts inside the assembly so they fit by construction. In-context references, layouts and skeletons — and how to keep them under control.

⏱ about 2–3 hours🧪 Lab: Skeleton-driven parts❓ 5-question quiz

1Today's goals

  • Create a new part in the context of an assembly
  • Read external reference symbols -> ->? ->* ->x
  • Drive parts from a layout sketch or skeleton part
  • Lock, break and list external references

2Bottom-up vs top-down

Bottom-upModel each part alone, then assemble. Simple, robust, best for standard and re-used parts.
Top-down (in-context)Model a part while inside the assembly, referencing other parts' geometry. It fits by construction and updates when the others change.

Tools: Insert ▸ Component ▸ New Part (pick a face/plane to sketch on), Edit Component on existing parts, Layout (Assembly tab ▸ Layout: blocks and a master sketch), and a skeleton part holding only key sketches and planes that every part references.

Symbol after a nameMeaning
->Has in-context (external) references, all found
->?Out of context — the referenced assembly is not open
->*References locked (frozen)
->xReferences broken

Right-click a part ▸ List External Refs → Lock All / Break All. Control behaviour in System Options ▸ External References (for example "Do not create references external to the model" while you want independent parts).

3Do it in SolidWorks: cover in context

  1. Open the gearbox housing assembly. Insert ▸ Component ▸ New Part, click the housing's top face.
  2. You are now editing the new part (the assembly goes transparent). Convert Entities the housing's outer edge and bolt holes.
  3. Extrude 10 mm. Exit editing (Confirmation Corner). Save the virtual part as an external file (right-click ▸ Save Part (in External File)).
  4. Note Cover^Gearbox ->. Change the housing's length — the cover follows.
  5. Close the assembly and open the cover alone: ->?.
  6. Back in the assembly: List External Refs ▸ Lock All. Change the housing again — the cover stays (->*).
  7. Skeleton exercise: a part Skeleton with a sketch of the two shaft centres; housing and cover reference it, not each other.

4Lab: skeleton-driven parts

The skeleton sets the shaft centre distance and bearing size. In top-down mode the housing and cover follow it. Switch to bottom-up, or lock the references, then move the skeleton and see the mismatch you would only find at assembly.

5Pro tips and common mistakes

  • Reference one master (skeleton or layout), not a web of parts referencing each other — circular references are slow and fragile.
  • Lock references when a design is released; parts used in other assemblies should not move because one assembly changed.
  • In-context parts used in two assemblies: references point to only one of them. Avoid, or break references after the design is frozen.
  • Mates on in-context parts: the part is already placed by the references — add only an InPlace mate (automatic) and nothing else.

6Practice

Create a gasket in context between the housing and cover: Convert Entities of the flange face and holes, extrude 1 mm. Then change the bolt count in the housing and check the gasket updates.
