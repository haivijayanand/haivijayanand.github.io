1. The problem

Every packet of chips holds one cricket card, picked at random from a set of 50, all equally likely. How many packets must you buy, on average, to complete the set?

Fifty packets is clearly not enough because of repeats. Maybe 70? 100?

2. The answer

≈ 225
packets on average for a set of 50 (exactly 224.96).
50
packets on average just for the last missing card.

The early cards come free; the last few are expensive. The final two cards alone take about 75 packets — a third of the total.

3. Working it out

Suppose you already hold k different cards. A new packet gives a new card with probability (n − k)/n, so on average you wait n/(n − k) packets for the next new one. Add the waits:

E[packets] = n/n + n/(n−1) + … + n/1 = n · (1 + 1/2 + 1/3 + … + 1/n) = n · Hn ≈ n(ln n + 0.5772)

For n = 50: H50 = 4.499, so 50 × 4.499 = 225. The spread is wide too: the standard deviation is about πn/√6 ≈ 62 packets.

6. Fine print

  • Swap with friends. If several collectors share duplicates, the cost per person falls sharply — the reason card-swapping playgrounds exist.
  • Companies who make some cards rare push the expected cost much higher; the formula above is the best case of equal chances.
  • The same sum appears in testing: how many random test inputs until every branch is hit, or how many random samples until every bin of a histogram is filled.
