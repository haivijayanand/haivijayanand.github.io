03See it: what a 3D model is made of

Blender stores a model as a mesh: vertices (points), edges joining them and faces filling them. The screen image is a projection of those 3D points onto 2D. Rotate the model, switch between perspective and orthographic views — the same choice an engineering drawing makes.

04Krita and OBS Studio

Krita

Krita began in 1998–99 as KImageShop inside the KDE desktop's office suite, was renamed (via Krayon) to Krita in 2002, and struggled for years as a general image editor. Its developers then focused on digital painting — brushes, pressure-sensitive pens, animation, comics tools. The Krita Foundation (2013) funds developers through donations and paid copies on Steam and the Microsoft Store. Krita 5.3 and Krita 6.0 — one release built on two generations of the Qt toolkit — arrived in March 2026; 32-bit Windows builds were dropped.

OBS Studio

Hugh "Jim" Bailey wrote Open Broadcaster Software in 2012 as a free alternative to paid streaming tools, then rewrote it as the cross-platform OBS Studio (from 2014). It composes "scenes" from sources — screen, camera, microphone, images, browser pages — and records or streams them, using FFmpeg and hardware encoders (Episode 15). It became the standard for Twitch and YouTube streamers, and during 2020 for teachers and lecturers running online classes. A 2021 dispute over a commercial fork using the "OBS" name ended with the fork renaming itself; version 31.1 (2025) added Windows on ARM.

05Linux on Windows: from Cygwin to WSL

ApproachYearsHow it workedFate
POSIX subsystem / Interix (Services for UNIX)1993–2013Windows NT's built-in Unix "personality" (Episode 06)Little used; removed in Windows 8.1
Cygwin1995 →A DLL that translates Unix calls into Windows calls; Unix programs are recompiled for itStill maintained (open source)
MinGW / MSYS21998 / 2013 →GCC compilers producing native Windows programs, with a Unix-like shell and package manager (pacman)Widely used; Git for Windows is built on it
Virtual machines1999 →A full Linux PC inside VMware or VirtualBox (2007, open-source core)Still common; VMware Workstation Pro became free (closed) in 2024
WSL 12016The Windows kernel translates Linux system calls (lxcore.sys) — no VM, no Linux kernelStill available; fast file access to Windows drives
WSL 22019/2020 →A real Linux kernel in a lightweight Hyper-V virtual machine, started in a second or twoThe default; GUI apps (WSLg, 2021), GPU compute, systemd (2022)

Microsoft first showed WSL at Build 2016 and shipped it in the Windows 10 Anniversary Update. Within hours of the announcement, the first issue raised on its GitHub tracker asked: "Will this be open source?" At Build 2025 Microsoft answered yes, publishing the command-line tools, background services and Linux-side components on GitHub; a few Windows kernel drivers such as lxcore.sys remain closed.

Getting started

wsl --install                 # installs WSL 2 and Ubuntu (admin prompt, then reboot)
wsl --list --online           # other distributions: Debian, openSUSE, Fedora...
wsl --install -d Debian
wsl --set-default-version 2
wsl --update                  # update the WSL package itself
# Inside Linux, Windows drives appear under /mnt/c ; from Windows open \\wsl$ in Explorer

Keep large project files inside the Linux file system for speed when working in WSL 2; files on /mnt/c are slower. On an offline LAN, distributions can be imported from a downloaded file with wsl --import.

09Lessons for engineers

  1. Users can save a product. Blender survived its company's bankruptcy because users paid to free it.
  2. Use your own tool for real work. Blender's open movies exposed weaknesses that bug reports never would.
  3. Focus wins. Krita succeeded only after choosing one job — painting — and doing it best.
  4. Run the right OS for the job. WSL lets Linux-only engineering codes (OpenFOAM, many solvers) run beside Windows tools on one PC.
