    How Word Search works

    A set of words from one theme is hidden in a square grid of letters. Find each word by selecting it in a straight line. Every word you find shows its meaning, so the game doubles as a vocabulary builder.

    How each puzzle is made

    1. Pick the words. Words are drawn at random from the chosen theme. A word is skipped if it is too long for the grid, or if it sits inside another chosen word (for example SUN inside SUNLIGHT), so every answer is unambiguous.
    2. Place the longest words first. Long words have the fewest legal positions, so they are placed while the grid is still empty.
    3. Try every position. For each word, the generator checks every starting cell in every direction allowed by the level. A position is legal if each grid square is either empty or already holds the same letter. About half the time it deliberately picks a position that shares a letter with an existing word, which makes the grid tighter and harder to scan.
    4. Fill the gaps. Empty squares get random letters weighted by how often they occur in English (lots of E, T, A; few Q, Z). This makes the filler look like real text, so words don't stand out.

    Selecting words

    Your drag snaps to the nearest of the 8 directions, so you don't have to be precise. A word counts whether you select it from its first letter or from its last. On the keyboard, move the dashed cursor with the arrow keys, press Space on the first letter, move to the last letter and press Space again.
