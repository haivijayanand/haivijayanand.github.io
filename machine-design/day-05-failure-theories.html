Theories of Failure and Factor of Safety

Knowing the stresses is half the job; deciding whether the part will fail is the other half. Learn the four classic theories of failure, which one to use for ductile and brittle materials, and how they turn combined stresses into one number to compare with the material's strength.

⏱ about 2–3 hours🧪 Lab: Failure envelopes❓ 5-question quiz

1Today's goals

  • State the maximum normal stress, maximum shear stress (Tresca) and distortion energy (von Mises) theories
  • Calculate the von Mises equivalent stress
  • Use Coulomb–Mohr for brittle materials
  • Get the factor of safety for combined bending and torsion
  • Know why Tresca is conservative and by how much

2Why theories are needed

A tensile test gives one number — the yield strength Sy, in a simple uniaxial stress. Real parts have two or three principal stresses at once. A failure theory predicts when that combination is as dangerous as the tensile test at yield.

3The theories

TheoryFailure whenFor
Maximum normal stress (Rankine)σ₁ ≥ Sut or σ₃ ≤ −SucBrittle materials (simple, approximate)
Maximum shear stress (Tresca, Guest)(σ₁ − σ₃)/2 ≥ Sy/2Ductile — simple and conservative
Distortion energy (von Mises, Hencky)σ′ ≥ SyDuctile — best agreement with tests
Coulomb–Mohr / modified Mohrσ₁/Sut − σ₃/Suc ≥ 1Brittle with Suc > Sut (cast iron)
von Mises stress (plane): σ′ = √(σ₁² − σ₁σ₂ + σ₂²) = √(σx² − σxσy + σy² + 3τxy²)
Shaft (σ, τ): σ′ = √(σ² + 3τ²) Tresca equivalent: √(σ² + 4τ²)
Factor of safety: n = Sy / σ′

For a shaft, substituting σ = 32M/πd³ and τ = 16T/πd³:

Tresca: d³ = (32n / πSy) · √(M² + T²)
von Mises: d³ = (32n / πSy) · √(M² + ¾T²)

4Pictures in the σ₁–σ₂ plane

Plot every combination of σ₁ and σ₂ that just causes failure and you get an envelope: a square for Rankine, a hexagon for Tresca, an ellipse through the hexagon's corners for von Mises. A stress state inside is safe; the distance to the boundary along the load line is the factor of safety.

Shear yield strength. In pure shear (σ₁ = −σ₂ = τ), Tresca predicts yield at τ = 0.5 Sy, von Mises at τ = 0.577 Sy. That 15.5 % gap is the largest difference between them. Many codes use Ssy = 0.5–0.577 Sy for this reason.

5Choosing by material

Ductile (elongation > 5 %)Use von Mises (or Tresca for a quick, safe answer). Base n on Sy.
Brittle (cast iron, hardened tool steel)Use Coulomb–Mohr or modified Mohr with Sut and Suc. Base n on ultimate strength, n ≥ 3.
Repeated loadsNone of these alone — use fatigue methods (Days 7–8). Static theories give the first-cycle yield check.

6Worked example

Day 4 shaft: is 40 mm enough in C45 (Sy = 380 MPa)?σ = 95.5 MPa, τ = 63.7 MPa von Mises σ′ = √(95.5² + 3 × 63.7²) = √(9120 + 12 173) = 145.9 MPa → n = 380/145.9 = 2.60 Tresca √(95.5² + 4 × 63.7²) = 159.2 MPa → n = 2.39 Both above 2 for static loads. (Fatigue is checked on Day 13.)

7Procedure

  1. Find the critical point and all stresses there (Day 4).
  2. Calculate principal stresses σ₁, σ₂, σ₃ (σ₃ = 0 on a free surface).
  3. Decide ductile or brittle from the elongation.
  4. Ductile: σ′ by von Mises; n = Sy/σ′. Brittle: Coulomb–Mohr with Sut and Suc.
  5. Compare n with the required factor of safety; resize if needed.

9Pro tips and common mistakes

  • Never use maximum normal stress theory for steel shafts in torsion — it overestimates strength by up to 2×.
  • FEA programs plot von Mises stress by default. It is always positive, so it hides whether the point is in tension or compression — check principal stresses too for brittle parts.
  • Hydrostatic stress (equal σ in all directions) does not cause yield. Von Mises knows this; Rankine does not.

10Practice

  1. A C45 bar (Sy 380) has σx = 150, τ = 90 MPa. Find n by Tresca and von Mises.
  2. An FG 260 cast-iron lever (Sut 260, Suc 900) has σ₁ = 60, σ₂ = −150 MPa. Find n by Coulomb–Mohr.
  3. Derive τ = 0.577 Sy for pure shear from the von Mises equation.
