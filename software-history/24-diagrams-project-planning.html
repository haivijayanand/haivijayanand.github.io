Diagrams and project planning: Visio, draw.io, MS Project and the Gantt chart

Engineers communicate in diagrams — flowcharts, block diagrams, P&IDs, wiring and network layouts — and they deliver work through plans with tasks, durations and dependencies. Both started on paper with stencils and wall charts. Software made them editable, shareable and, more recently, writable as plain text.

02The methods came first: Gantt, CPM and PERT

Henry Gantt, a colleague of F. W. Taylor, drew horizontal bar charts of work against time in the 1910s; the Polish engineer Karol Adamiecki had published a similar "harmonogram" earlier. Gantt charts were used for wartime production and large works such as the Hoover Dam.

In 1957 DuPont and Remington Rand developed the Critical Path Method (CPM) to plan plant maintenance shutdowns on a UNIVAC computer. In 1958 the US Navy's Polaris missile programme developed PERT, which used three time estimates (optimistic, most likely, pessimistic) for each task. Both describe a project as a network of tasks; the longest path through it — the critical path — sets the finish date. Any delay on it delays the project; other tasks have float.

03Try it: critical path and Gantt chart

A small plan to commission a new test rig. Edit durations (days) or the predecessor IDs, and the schedule recalculates — exactly what MS Project or Primavera does on a larger scale. Navy bars are critical; blue bars have float, shown as the amber outline.

06Diagrams as code

A drawing must be re-drawn when the system changes; text can be edited, compared and stored in Git with the rest of a project. Graphviz (AT&T Bell Labs, 1991) lays out graphs written in the DOT language. PlantUML (2009) generates UML from text. Mermaid (2014) renders flowcharts, sequence diagrams and Gantt charts from Markdown-like text, and is supported directly by GitHub, GitLab, Obsidian and Notion.

gantt
  title Rig commissioning
  dateFormat YYYY-MM-DD
  Foundation      :a1, 2026-12-01, 5d
  Install rig     :a2, after a1, 4d
  Instrumentation :a3, after a2, 3d

The same plan as a Mermaid Gantt chart: a few lines of text that a web page draws as a chart.

08Files and formats

  • MS Project .mpp is closed, but Project can save to XML, which GanttProject and ProjectLibre import. Primavera uses .xer and XML for exchange.
  • Visio .vsdx (2013 onward) is a ZIP of XML; draw.io and LibreOffice can import it with some loss.
  • draw.io files are XML and can be embedded in a PNG or SVG, so the picture is also the editable source.
  • Text diagrams (Mermaid, DOT, PlantUML) are the most portable — and work well in reports and README files.

10Lessons for engineers

  1. Know your critical path. Effort spent speeding up non-critical tasks does not bring the finish date closer.
  2. Dependencies are the plan. A Gantt chart without links is just a drawing.
  3. Keep diagram source files. A PNG in a report cannot be edited; keep the .drawio or text file beside it.
  4. Match the tool to the work. Kanban for flowing tasks, CPM for physical projects with fixed sequences.
