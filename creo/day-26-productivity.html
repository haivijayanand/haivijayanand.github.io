28-Day Creo Parametric Course · Week 4 · Day 26

Flexible Modeling, config.pro and Mapkeys

Work faster in Creo. Edit imported or messy geometry with Flexible Modeling, set up config.pro so every session starts right, and record mapkeys for the clicks you repeat a hundred times a day.

⏱ about 2–3 hours🧪 Lab: config.pro + mapkey planner❓ 5-question quiz

1Today's goals

  • Use Flexible Modeling: Move, Offset, Modify Analytic, Substitute, Remove, Pattern Recognition
  • Know where config.pro is read from and in what order
  • Set templates, units, folders and behaviour options
  • Record, save and share mapkeys
  • Keep a company standards folder

2Flexible Modeling

The Flexible Modeling tab edits geometry directly — faces, not features — while keeping the result as a feature in the tree. Ideal for imported STEP parts and for quick changes to models you do not want to rebuild.

MoveMove or rotate a set of faces (e.g. a boss) with a dragger or by dimensions; the neighbours stretch to follow.
Offset / Modify AnalyticOffset faces; change a cylinder's radius or a cone's angle directly.
RemoveRemove a round, hole or boss from imported geometry.
RecognitionPattern and symmetry recognition find repeated geometry so one edit changes all instances.

config.pro

config.pro is a text file of option value lines. Creo reads it at start-up from the installation's text folder, then the start-in folder, then (for some options) the working directory — later files win. File ▸ Options ▸ Configuration Editor shows every option, its value and its source.

Mapkeys

A mapkey is a recorded sequence of commands fired by a short key sequence. File ▸ Options ▸ Environment ▸ Mapkeys Settings (or Tools ▸ Mapkeys in older releases) ▸ New ▸ give keys and a name ▸ Record ▸ do the clicks ▸ Stop ▸ OK ▸ Save Changed. Creo writes them into config.pro.

3Do it in Creo

  1. Import a STEP file (any bracket) with File ▸ Open. On the Flexible Modeling tab, select a boss's faces (Shape Surface set) ▸ Move using Dimensions 10 mm. Finish.
  2. Modify Analytic: pick a hole, change Ø8 → Ø9. Remove: pick a round's face — it is gone.
  3. Close Creo. Make a folder C:\creo_std with sub-folders templates, formats, dtl, materials.
  4. Build your config.pro with the lab below. Save it in your Creo start-in folder (see the desktop shortcut's Properties ▸ Start in).
  5. Restart Creo. File ▸ Options ▸ Configuration Editor: check each option and its source file.
  6. Record a mapkey vf: Saved Orientations ▸ FRONT, then Refit. Stop, OK, Save Changed. Type vf in the graphics window.
  7. Record em: File ▸ Manage Session ▸ Erase Not Displayed ▸ OK.

4Lab: config.pro and mapkey planner

Tick the options you want, edit the values, and plan your mapkeys. The lab writes a config.pro you can copy and warns about key clashes.

5Pro tips and common mistakes

  • Keep one company config.pro under version control and copy it to every PC; personal mapkeys go in a second file loaded after it.
  • Do not put company options in a working directory's config.pro — they will change behaviour only for some jobs and confuse everyone.
  • Prefix your mapkeys with a letter nobody types in the graphics window (e.g. ; or two letters).
  • Mapkeys that open dialogs can pause for input — tick "Pause" options when recording if a step needs the user.
  • Flexible Modeling on native parts is fine for quick edits, but a feature edit is usually cleaner when the history is good.

6Practice

  1. Write your config.pro with templates, formats, dtl, materials, trail_dir and units. Restart and verify each in the Configuration Editor.
  2. Record five mapkeys you will use daily (views, erase, save-close, datum display toggles). Use them for one full day.
  3. Import a STEP casting, remove all its small rounds with Flexible Modeling, move a boss, and export it again.
