Fixed IP addresses for home devices
Home › Utilities · find IP and MAC, then reserve them on the router

Your router hands out addresses to every device on the Wi-Fi, and an address can change after a restart. Tools that control a device over Wi-Fi (the TV lock, FocusGuard's phone page, a network printer, a CCTV recorder) need the address to stay the same. The fix is a few minutes on the router page, and nothing changes on the device itself.

Reserving (also called binding) means telling the router: "whenever the device with this MAC joins, always give it this IP".

One device can have two MACs: a PC or TV has one for Wi-Fi and another for its LAN cable port. Reserve the one it actually uses. If you switch it from Wi-Fi to cable later, add a reservation for the cable MAC too.

1 · Find IP and MAC on the router

  1. Connect a phone or PC to the home Wi-Fi and open a browser.
  2. Type the router address in the address bar: usually 192.168.1.1, sometimes 192.168.0.1, 192.168.29.1 (JioFiber) or 192.168.1.254. The sticker under the router shows the address and the login. On a Windows PC, ipconfig shows it as Default Gateway.
  3. Log in. The user is often admin, and the password is on the sticker. Some ISPs (JioFiber, Airtel) let you do the same from their own app.
  4. Open the device list. Its name depends on the router: Connected Devices, Attached Devices, DHCP Client List, LAN Host, Device Info › DHCP, or Status › LAN.
  5. Each row shows a name (host name), an IP address, a MAC address and often the remaining lease time. Note down the rows for the PC and the TV.

Typical names: a Windows PC shows its computer name (DESKTOP-4K7Q2LM or whatever you named it), an Android TV shows its model or android-…, a phone shows its model or the owner's name.

3 · Which device is which?

  • Match the MAC you saw on the device with the router list. This is the surest way.
  • Switch it off and refresh the router's device list. The row that disappears is that device.
  • Look at the first half of the MAC. The first six characters identify the maker (search "MAC lookup" online and paste them in).
  • Rename your PC to something clear (Settings › System › About › Rename this PC) so it is easy to spot.

The random-MAC trap

Phones, and Windows 11 if you turn it on, can use a made-up "private" MAC for privacy. A reservation is tied to the MAC, so it can stop working if the MAC changes.

  • Windows 11: Settings › Network & internet › Wi-Fi › your network › Random hardware addresses: Off.
  • Android phone or TV: Wi-Fi network settings › Privacy › Use device MAC (or "Phone MAC").
  • iPhone: Wi-Fi › ⓘ › Private Wi-Fi Address: Off (or "Fixed").

Change this before noting the MAC, then reconnect, then reserve. Normally only the PC and TV need a reservation; the phones that control them don't.

4 · Reserve (bind) the IP on the router

  1. On the router page, find the reservation screen. It is usually inside LAN, DHCP or Network, and is called one of: Address Reservation, DHCP Reservation, Static Lease, DHCP Binding, DHCP Static IP or IP & MAC Binding.
  2. Click Add (or New). Many routers let you pick the device from the connected list; otherwise type the MAC and the IP yourself. The MAC is usually accepted with colons or dashes.
  3. Choose the IP. Simplest is to keep the address the device has now. If you choose a new one, use an address nobody else has and keep the first three parts the same as the router's (router 192.168.1.1 → device 192.168.1.8). Some routers only accept addresses inside their DHCP range (shown on the DHCP page, e.g. .2 – .254); the router will say so if you get it wrong.
  4. Give it a clear name ("TV-hall", "Kids-PC") if there is a box for it, then Save or Apply. Repeat for every device you want fixed.
  5. Reconnect the device so it picks up the reserved address: restart it, or switch its Wi-Fi off and on. A few routers need their own reboot first.
A reservation fixes the address only on your Wi-Fi. A factory reset of the router, or the ISP replacing it, wipes the list. Take a photo of the reservation screen so you can enter it again.

Three things that sound alike

WhatWhere you set itUse it?
DHCP reservation (binding, static lease)RouterYes. One place to manage everything; the device needs no change.
Static IP typed on the deviceDevice's network settingsOnly if the router has no reservation. You must also enter the gateway and DNS, and pick an address outside the router's DHCP range, or two devices may clash.
ARP / IP-MAC binding (security)Router's Security menuNot needed at home. It blocks devices whose IP and MAC don't match the list, and can lock out guests.

5 · Check it worked

  • The router's device list shows the device at the reserved IP. Some routers show the lease as Infinity, Static or Reserved.
  • Restart the device and check again: same address.
  • From a PC, ping 192.168.1.8 (your device's address) gets replies.
  • Now put those addresses into your tools: the TV= and PC= lines of home_lock.sh, and the phone bookmark for FocusGuard.

Problems

What you seeLikely cause and fix
Device still gets the old IPIt kept its old lease. Restart the device, or reboot the router.
Router says "IP in use" or "conflict"Another device has that address. Pick a different number, or reserve that other device somewhere else first.
Router says "IP out of range"The router only reserves inside its DHCP pool. See the start and end addresses on the DHCP page and choose one between them.
Worked, then stopped after a few daysRandom MAC is on (see the trap above), or the device moved between Wi-Fi and cable.
Can't open the router pageCheck the Default Gateway with ipconfig. Use the router's Wi-Fi, not mobile data. Some ISP routers only allow changes from their app.
