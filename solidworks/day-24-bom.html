28-Day SolidWorks Course · Week 4 · Day 24

BOMs, Balloons, Revision and Other Tables

Assembly drawings need a parts list. Insert a Bill of Materials that reads custom properties, balloon it, and add revision and other tables.

⏱ about 2–3 hours🧪 Lab: Three BOM types❓ 5-question quiz

1Today's goals

  • Insert a BOM and choose Top-level, Parts only or Indented
  • Link BOM columns to custom properties
  • Add Auto Balloons and stacked balloons
  • Use revision, hole, general and weld tables

2BOMs come from properties

Annotation ▸ Tables ▸ Bill of Materials (select a view). Columns can be Item No., Quantity, Part Number (file name, configuration name or $PARTNUMBER) and any custom property — Description, Material, Weight, Vendor. That is why Day 1 put properties in the template.

BOM typeShowsWho uses it
Top-level onlyDirect children; sub-assemblies as one lineFinal assembly
Parts onlyEvery part, quantities rolled up, no sub-assembliesPurchase, stores
IndentedThe structure, numbered 1, 2, 2.1, 2.2…Planning, full assembly drawings

Options: configurations to list, Part configuration grouping (one line per configuration or combined), Keep missing items, Item numbers follow assembly order or BOM order. Balloons: Auto Balloon (square, circular, around the view), Balloon, Stacked Balloon (for screws + washers).

Other tables: Revision table (with revision symbols), Hole table (X/Y of every hole from an origin), General table, Weld table, Bend table (sheet metal), Cut list (weldments, Day 25), design table display.

3Do it in SolidWorks

  1. Drawing of the gearbox assembly: isometric exploded view (View Properties ▸ Show in exploded state).
  2. Tables ▸ Bill of Materials ▸ template bom-standard ▸ Indented. Place it above the title block.
  3. Right-click a column header ▸ Insert column ▸ Custom property ▸ Material. Add Weight.
  4. Switch to Parts only — note quantities roll up.
  5. Annotation ▸ Auto Balloon: layout Square, balloon style Circular, follow assembly order.
  6. Stacked balloon for bolt + washer + nut.
  7. Revision table: add revision A "First issue", B "Bolt size changed".

4Lab: three BOM types

The same gearbox structure in each BOM type. Look at how the bearing quantity changes in Parts only (two inside a sub-assembly plus one spare at the top).

5Pro tips and common mistakes

  • Fix data at the source — in the part's custom properties — never type over BOM cells (it breaks the link).
  • Toolbox parts should carry descriptions like "Hex bolt ISO 4017 M8×25 8.8" via Toolbox settings.
  • Exclude reference parts (fixtures, envelopes) with Exclude from bill of materials on the component.
  • Save your BOM layout as a template (right-click ▸ Save As) so every drawing looks the same.

6Practice

Make the gearbox general-arrangement drawing: exploded iso view, indented BOM with Material and Weight, auto balloons, a revision table and a parts-only BOM on sheet 2 for purchase.
