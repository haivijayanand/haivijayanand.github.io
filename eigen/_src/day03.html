Put the eigenvectors side by side as the columns of P and the matrix becomes diagonal: A = P D P⁻¹. Powers become trivial, Aᵏ = P Dᵏ P⁻¹, and the long-run fate of anything that repeats a step — market shares, weather, machine condition, a population — is read straight from the largest eigenvalue and its eigenvector.

    1Diagonalisation: changing to the matrix's own coordinates

    Collect the eigen-equations Avᵢ = λᵢvᵢ for all n eigenvectors into one matrix equation. With P = [v₁ v₂ … vₙ] (eigenvectors as columns) and D = diag(λ₁, …, λₙ):

    A P = P D ⟹ A = P D P⁻¹

    Read it right to left: P⁻¹ expresses a vector in eigen-coordinates, D scales each coordinate by its own λ, P converts back. In eigen-coordinates the matrix is just a list of independent stretch factors. This works whenever A has n independent eigenvectors — always for distinct eigenvalues, always for symmetric matrices, but not for defective ones.

    Powers collapse because the inner P⁻¹P pairs cancel:

    A² = P D P⁻¹ P D P⁻¹ = P D² P⁻¹ Aᵏ = P Dᵏ P⁻¹, Dᵏ = diag(λ₁ᵏ, …, λₙᵏ)
    Example 1 — A = [4 1; 2 3] raised to the 10th powerFrom Day 2: λ = 5, v = (1, 1); λ = 2, v = (1, −2) P = [1 1; 1 −2], P⁻¹ = [2/3 1/3; 1/3 −1/3] Aᵏ = 5ᵏ·[2/3 1/3; 2/3 1/3] + 2ᵏ·[1/3 −1/3; −2/3 2/3] k = 10: 5¹⁰ = 9 765 625, 2¹⁰ = 1024 A¹⁰ = [6 510 758 3 254 867 ; 6 509 734 3 255 891] The λ = 5 part is 9500 times larger: after a few steps A¹⁰ ≈ 5¹⁰ × (rank-one matrix built from v₁).
    Example 2 — Fibonacci numbers in one line(Fₖ₊₁, Fₖ) = [1 1; 1 0]·(Fₖ, Fₖ₋₁) Eigenvalues: λ² − λ − 1 = 0 → φ = 1.618 (golden ratio) and −0.618 The −0.618ᵏ part dies out, so Fₖ ≈ φᵏ/√5 F₃₀ ≈ φ³⁰/√5 = 832 040.0 (exact: 832 040)

    2The largest eigenvalue wins

    Write any starting vector as a mix of eigenvectors, x₀ = c₁v₁ + c₂v₂ + … Then after k steps

    xₖ = Aᵏx₀ = c₁λ₁ᵏ v₁ + c₂λ₂ᵏ v₂ + … = λ₁ᵏ [ c₁v₁ + c₂(λ₂/λ₁)ᵏ v₂ + … ]

    If |λ₁| is strictly the largest, every ratio (λᵢ/λ₁)ᵏ → 0. So whatever you start with, the shape of xₖ ends up along v₁, and it grows (or shrinks) by λ₁ per step. The ratio |λ₂/λ₁| sets how fast the start is forgotten: the error shrinks by that factor every step. This is the theme of the rest of today, and the basis of the power method of Day 10.

    3Markov chains: where does everyone end up?

    A Markov chain moves between states with fixed probabilities. Collect them in a transition matrix P whose entry Pᵢⱼ is the probability of going from state j to state i in one step; each column adds up to 1. If xₖ holds the fractions in each state, then xₖ₊₁ = P xₖ.

    Because the columns add to 1, the row vector (1, 1, …, 1) satisfies (1,…,1)P = (1,…,1): P always has the eigenvalue λ = 1. For a chain where every state can eventually reach every other (and it is not periodic), all other eigenvalues have |λ| < 1 (Perron–Frobenius theorem). So the chain settles onto the eigenvector of λ = 1 — the steady state — from any start.

    Example 3 — brand loyaltyEach month: Brand A keeps 80 % of its customers, B keeps 75 %, C keeps 75 %; the rest switch as in the lab's first scenario. Solve (P − I)x = 0 with x₁ + x₂ + x₃ = 1: steady state A 38.5 %, B 30.8 %, C 30.8 % Other eigenvalues 0.65 ± 0.03i → |λ₂| = 0.651 Gap to steady state after k months ∝ 0.651ᵏ → within 1 % after ln 0.01 / ln 0.651 ≈ 11 months. Starting market shares do NOT matter in the long run; the switching rates do.
    Example 4 — machine condition and availabilityStates: Good, Worn, Down. Monthly: Good → Worn 8 %, Good → Down 2 %, Worn → Down 15 %, a Down machine is repaired to Good with probability 60 % per month. Steady state: Good 58.8 %, Worn 31.4 %, Down 9.8 % Long-run availability = 1 − 0.098 = 90.2 % Cut the Worn → Down rate by preventive maintenance and watch "Down" fall in the lab.
    Where Markov chains runCustomer churn and market share, credit-rating migration in banks, reliability and availability of repairable equipment, queues, speech recognition and text prediction, weather generators, the random surfer of Google (Day 8), board games such as Snakes and Ladders.

    4Populations: the Leslie matrix

    Divide a population into age classes (fish by year, cattle by age, trees by size). Each period, class i produces Fᵢ offspring per individual and a fraction sᵢ survives into the next class:

    L = [F₁ F₂ F₃ F₄ ; s₁ 0 0 0 ; 0 s₂ 0 0 ; 0 0 s₃ 0], xₖ₊₁ = L xₖ

    The dominant eigenvalue λ₁ is the growth factor per period, and its eigenvector is the stable age distribution that every population converges to. Fisheries and wildlife managers set harvest quotas so that λ₁ stays at or just above 1.

    Example 5 — four age classesF = (0, 1.5, 1.2, 0.5), s = (0.5, 0.7, 0.6) λ₁ = 1.103 → the population grows 10.3 % per period, doubling every ln 2 / ln 1.103 = 7.1 periods Stable age distribution: 52.7 % / 23.9 % / 15.2 % / 8.2 % R₀ = 0 + 0.5·1.5 + 0.5·0.7·1.2 + 0.5·0.7·0.6·0.5 = 1.275 > 1 → growth (λ₁ > 1 ⇔ R₀ > 1)
    Why λ = 1 is the largest eigenvalue of a stochastic matrix

    For a column-stochastic P, take any eigenvector Pv = λv and add up absolute values: Σᵢ|λvᵢ| = Σᵢ|Σⱼ Pᵢⱼvⱼ| ≤ Σⱼ(Σᵢ Pᵢⱼ)|vⱼ| = Σⱼ|vⱼ|. So |λ| ≤ 1. And λ = 1 occurs because Pᵀ has the all-ones eigenvector, and A and Aᵀ have the same eigenvalues (same determinant). The Perron–Frobenius theorem adds that for a positive (or irreducible, aperiodic) matrix the eigenvalue 1 is simple and its eigenvector can be chosen with all entries positive — a genuine probability distribution.
