Turbo Pascal, Delphi and Visual Basic: programming for everyone

Before 1983, compiling a program on a PC meant expensive tools, several floppy-disk passes and long waits. Turbo Pascal made compiling almost instant and cheap; Visual Basic and Delphi then let you draw a Windows program and write only the code behind each button. Together they created a generation of programmers.

01The requirement: shorten the loop between idea and running program

Early PC programmers had two poor choices. BASIC interpreters (BASICA, GW-BASIC) were built in and easy, but slow and unstructured. Compilers produced fast programs but cost hundreds of dollars, needed separate editor, compiler and linker programs, and swapped floppy disks for every build — minutes per change. Later, Windows made it worse: a "Hello" window in C needed about a hundred lines of message-loop code (Episode 02).

03Technology inside

  

    
ToolKey technology

    
Turbo PascalSingle-pass compiler written in assembly by Anders Hejlsberg; editor (with WordStar keys), compiler and run-time together in memory; output straight to a .COM file; errors jumped the cursor to the faulty line. Later: units (4.0), integrated debugger (5.0), objects (5.5), Turbo Vision text-mode windows (6.0)

    
Visual BasicForm designer from Alan Cooper's "Ruby" prototype joined to Microsoft's QuickBASIC language; event-driven model; interpreted p-code until VB5 added a native compiler; COM/ActiveX components

    
DelphiObject Pascal with a fast native-code compiler; the Visual Component Library (VCL) written in Delphi itself, so components could be extended; database access through the Borland Database Engine; single stand-alone .EXE output

  






  
04Version explorer

  
Blue chips: Borland's Turbo Pascal and Delphi. Amber chips: Microsoft's Visual Basic and its successors.

  

  

  
One person links the two halves: Anders Hejlsberg wrote Turbo Pascal, was chief architect of Delphi, then moved to Microsoft in 1996 where he led the design of C# (2000) and later TypeScript (2012). Delphi's components, properties and events reappear in C# and .NET.

06Retirements — and a survivor

  
    
    
  • Turbo Pascal: ended with Turbo Pascal 7 / Borland Pascal 7 (1992); Delphi took over. Borland later released old Turbo versions free as "antique software".
    • 
    
  • Classic Visual Basic: VB.NET (2002) was a different language on .NET, and VB6 code did not move across easily. Many companies stayed on VB6. Microsoft ended support for the VB6 IDE in April 2008, but the VB6 runtime still ships with Windows so old programs keep running. VBA, VB's sibling, lives on in Office.
    • 
    
  • VB.NET: still supported, but since 2020 Microsoft has said it will not add new language features.
    • 
    
  • Delphi: not retired. Borland spun off its tools as CodeGear (2006), sold to Embarcadero in 2008. Delphi 13 "Florence" (September 2025) added a 64-bit IDE and AI components; it builds for Windows, macOS, Linux, Android and iOS.
    •

08Lessons for engineers

  
    
    
  1. Speed of feedback shapes how people think. Seconds instead of minutes turned programming into experimentation.
    2. 
    
  2. Price creates a community. A US$ 50 compiler made students into professionals.
    3. 
    
  3. Breaking compatibility strands users. VB.NET's break left VB6 applications running for decades.
    4. 
    
  4. A good architecture travels with its architect. Turbo Pascal → Delphi → C# → TypeScript.
