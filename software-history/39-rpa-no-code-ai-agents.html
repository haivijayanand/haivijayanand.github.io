RPA, no-code and AI agents: software that operates software

The newest layer of automation does not live inside any one program. Software "robots" click through screens like a clerk; no-code services connect hundreds of web applications with "when this happens, do that" rules; and since 2023 AI assistants have begun to plan and carry out multi-step tasks themselves. This episode closes Season 7 by tracing that journey from back-office robots to AI agents — and the cautions that come with each.

02Robotic process automation

"Robots" in RPA are programs, not machines: they log in, read screens, copy values and press buttons as a person would, but faster and without tiring. They descend from screen-scraping, test-automation tools (Episode 37) and macro recorders.

03No-code integration: "when this, then that"

2007 — Yahoo Pipes. A visual editor for combining web feeds; closed in 2015, but its idea lived on.
December 2010 — IFTTT. Linden Tibbets' "If This Then That" made simple applets popular with consumers and smart-home users.
October 2011 — Zapier. Wade Foster, Bryan Helmig and Mike Knoop built business connectors ("Zaps") between thousands of web apps.
2012 — Integromat, now Make. Visual multi-step "scenarios" from Prague; renamed Make in 2022.
2016–2019 — Microsoft Flow → Power Automate. Cloud flows connected to Microsoft 365, SharePoint, Teams and Outlook; renamed Power Automate in 2019 and joined by desktop RPA.
2019 — n8n. Jan Oberhauser's node-based tool from Berlin can be self-hosted, keeping data inside the organisation; its "fair-code" licence publishes the source with limits on commercial resale.

05AI copilots and agents

  

    
2021 — Code copilots. GitHub Copilot suggested code inside editors — the first mass-market AI assistant for programmers.

    
2022–2023 — Chat assistants and tool use. ChatGPT (November 2022) and other assistants were soon able to call "tools" — search, calculators, databases, e-mail — through structured function calls. Microsoft 365 Copilot and Google's Gemini for Workspace put assistants into office software.

    
2024 — Computer use and connectors. AI models were given the ability to look at screenshots and move the mouse and keyboard, operating ordinary desktop and browser programs much as an RPA robot does, but guided by language instructions rather than a fixed script. Open protocols such as the Model Context Protocol (November 2024) standardised how assistants connect to files, databases and business tools.

    
2025–2026 — Agents in the workflow. RPA vendors (UiPath, Automation Anywhere), Power Automate and n8n added AI-agent steps; office suites and browsers added agents that can carry out multi-step tasks, usually asking for confirmation before actions with consequences.

Cautions for official and engineering work. Do not send classified, proprietary or personal data to public AI services; follow your organisation's approved tools. Give agents the least access needed; require confirmation for sending, deleting, paying or changing records; and check AI-produced numbers, references and code before relying on them (see the AI section of Episode 23).






  
06Ready-to-use examples

  
A. E-mail a test summary with the file attached (Python, standard library)

  
"""Find the newest CSV in a folder, compute the max of one column and e-mail
the summary with the file attached. Use your organisation's approved mail relay."""
import csv, smtplib
from email.message import EmailMessage
from pathlib import Path

FOLDER = Path(r"D:\Archive\Data")
COLUMN = "Oil_Temp_C"
LIMIT = 85.0

latest = max(FOLDER.glob("*.csv"), key=lambda p: p.stat().st_mtime)
with latest.open(newline="") as f:
    values = [float(r[COLUMN]) for r in csv.DictReader(f) if r[COLUMN]]
peak = max(values)
status = "ALERT" if peak > LIMIT else "OK"

msg = EmailMessage()
msg["Subject"] = f"[{status}] {latest.name}: max {COLUMN} = {peak:.1f}"
msg["From"] = "testlab@example.org"
msg["To"] = "team@example.org"
msg.set_content(f"File: {latest.name}\nRows: {len(values)}\nMax {COLUMN}: {peak:.1f} (limit {LIMIT})")
msg.add_attachment(latest.read_bytes(), maintype="text", subtype="csv", filename=latest.name)

with smtplib.SMTP("smtp.example.org", 25) as server:   # replace with your relay
    server.send_message(msg)
print("sent:", msg["Subject"])

Step 1  : Get file content
Step 2  : Condition — file name ends with ".xlsx"
Step 3  : Run script (Office Script that reads cell D2 "Max oil temp", Episode 36)
Step 4  : Condition — result > 85
   Yes  : Post message in a Teams channel — "Oil temperature alert in <file name>"
   No   : (nothing)
Step 5  : Send an e-mail (V2) to the lab group with a link to the file


  
C. Instructions for an AI assistant that summarises test logs safely

  
Role: You summarise endurance-test logs for engineers.
Input: one CSV file with columns Time, Speed_rpm, Oil_Temp_C, Vib_RMS_mm_s.
Do:
  1. Report run duration, mean and maximum of each numeric column.
  2. List every period where Oil_Temp_C > 85 or Vib_RMS_mm_s > 4.5, with start and end times.
  3. Show the calculations or code you used so the numbers can be checked.
Do not:
  - guess values that are not in the file, or invent causes;
  - change, delete or send any file;
  - include data in your answer beyond what is needed for the summary.
If the file is incomplete or columns are missing, say so and stop.

09Lessons

  
    
    
  1. Fix the process before automating it. A robot that copies a bad process makes mistakes faster.
    2. 
    
  2. APIs first, screens last, AI where judgement is needed. Each layer is less predictable than the one before.
    3. 
    
  3. Someone must own every bot. Automations need monitoring, credentials management and updates when systems change.
    4. 
    
  4. Keep humans in the loop for consequences. Reports can be automatic; approvals, payments and safety decisions need a person.
    5.
