01The requirement: a real operating system for the PC

Episode 01 showed the limits built into DOS. By the mid-1980s the Intel 286 and 386 offered protected mode, memory beyond 1 MB, and hardware support for multitasking — but DOS could not use them. Businesses also wanted PCs to act as reliable servers on networks, which DOS could never do.

02The partnership and the split

1985IBM and Microsoft agree to develop a new OS together
Apr 1987OS/2 announced with IBM's PS/2 computers
Dec 1987OS/2 1.0: text-mode only, written for the 286, one DOS program at a time
Oct 1988OS/2 1.1 adds the Presentation Manager GUI; Microsoft hires Dave Cutler to build a portable "NT OS/2"
May 1990Windows 3.0 is a huge success; Microsoft shifts its priority to Windows
1990–1991The partnership breaks up: IBM keeps OS/2 2.0; Microsoft turns NT OS/2 into Windows NT with the Win32 API
1992–1996OS/2 2.0 and Warp fight Windows 3.1 and Windows 95 in the market
The disagreement was partly technical (IBM wanted to keep supporting the 286 in its PS/2 line; Microsoft wanted a 386 design) and partly commercial: Windows 3.0 showed Microsoft it could own the next platform alone.

04Technology inside

OS/2 (2.x and Warp)

Kernel32-bit for the 386 (from 2.0), with 16-bit parts inherited from 1.x
InterfaceWorkplace Shell: an object-oriented desktop built on IBM's SOM; drag a file onto a printer to print it
File systemHPFS: long file names, less fragmentation
CompatibilityVirtual DOS machines; Win-OS/2 ran Windows 3.x programs
Weak pointThe "synchronous input queue": one stuck GUI program could still freeze the desktop

Windows NT

KernelHybrid design influenced by DEC's VMS and microkernels; written mostly in C for portability
PortabilityHardware Abstraction Layer (HAL); ran on x86, MIPS, DEC Alpha and PowerPC
SubsystemsWin32 plus OS/2 1.x and POSIX "personalities"; Win16 programs via WOW
File systemNTFS: journaling, permissions, large disks
OtherUnicode throughout, symmetric multiprocessing, security model with access control lists

05Version explorer

Blue chips: OS/2. Amber chips: Windows NT.

The compatibility trap: OS/2 2.x was marketed as "a better DOS than DOS and a better Windows than Windows". It ran Windows programs so well that software companies saw no reason to write native OS/2 programs — so buyers saw no reason to choose OS/2.

07OS/2's retirement — and its afterlife

  • OS/2 Warp sold millions of copies but never won application developers. In 1996–97 IBM shifted OS/2 towards business and network computing.
  • IBM stopped selling OS/2 in December 2005 and ended standard support on 31 December 2006.
  • OS/2 kept running ATMs, bank branch systems, railway and transit control systems for years, valued for stability.
  • Licensed successors continued it: eComStation (2001) and ArcaOS (2017), which is still sold for maintaining legacy OS/2 systems.

08NT's long life

NT 3.1 · 1993→NT 4.0 · 1996→Windows 2000→XP · 2001→Vista / 7 / 8→Windows 10 / 11

Windows XP (2001) brought NT to home users and ended the DOS-based Windows line. Every Windows PC, server, Xbox and HoloLens today runs a descendant of the kernel that Cutler's team started in 1988.

09Lessons for engineers

  1. Good technology loses without developers. Platforms are won by the programs written for them.
  2. Running a rival's software perfectly can help the rival.
  3. Design for the next hardware, not the current one. NT targeted 32-bit processors and portability; OS/2 1.x was tied to the 286.
  4. A clean architecture pays off for decades. NT's core has outlived every product built around it.
