Tables, Repeat Regions, BOMs and Balloons

Creo tables are smarter than they look: repeat regions read the assembly and fill themselves. Learn tables, repeat regions with report parameters, BOM types, balloons, and indented vs flat lists.

⏱ about 2–3 hours🧪 Lab: Three BOM types❓ 5-question quiz

1Today's goals

  • Insert and format tables
  • Add a repeat region with &rpt.index, &asm.mbr.name, &rpt.qty
  • Read custom parameters into a BOM (&asm.mbr.PART_NO)
  • Make flat (parts only) and indented BOMs
  • Create and clean up balloons

2Tables and repeat regions

A repeat region is a row of a table that Creo copies once for every member of the assembly, filling in report parameters.

Report parameterShows
&rpt.indexItem number
&asm.mbr.nameComponent name
&asm.mbr.PART_NO, &asm.mbr.DESCRIPTIONYour own model parameters
&rpt.qtyQuantity
&rpt.levelIndent level in a multi-level region
&asm.mbr.typePart or assembly
Attributes of a repeat region decide its type: Duplicates (one row per instance) vs No Duplicates (one row per part with qty), Flat (only top level) vs Recursive (every level). Recursive + No Duplicates = a parts list for purchase; multi-level with &rpt.level = an indented BOM. Filters drop items like skeletons and bulk items.

Balloons: Table ▸ Create Balloons uses the repeat region's index numbers, so balloons and BOM always agree.

3Do it in Creo

  1. Drawing of your shaft unit assembly. Table ▸ Table ▸ insert 2 rows × 4 columns at the title block's top edge.
  2. Header row: ITEM, PART NO., DESCRIPTION, QTY.
  3. Table ▸ Repeat Region ▸ Add ▸ Simple ▸ pick the first and last cell of row 2.
  4. Double-click each cell of row 2: Report Symbol ▸ rpt ▸ index; asm ▸ mbr ▸ User Defined ▸ PART_NO; same for DESCRIPTION; rpt ▸ qty.
  5. Table ▸ Update Tables. Rows appear for every component.
  6. Repeat Region ▸ Attributes ▸ No Duplicates + Recursive: a flat parts list with quantities rolled up.
  7. Table ▸ Create Balloons ▸ All. Then Clean up Balloons and drag them to tidy positions.

4Lab: three BOM types

The same assembly as top-level, parts-only and indented lists.

5Pro tips and common mistakes

  • Save a good BOM table (Table ▸ Save As Table) and put it in your drawing template — never build one by hand again.
  • Give every part the same parameters (PART_NO, DESCRIPTION, MATERIAL) through the start template, so BOMs fill in.
  • Filter skeletons and reference-only parts out of the repeat region; mark bulk items (grease, adhesive) with a BOM-only parameter.
  • Fix sort order with Repeat Region ▸ Sort Regions (by PART_NO, then by type).
  • Family-table instances show their own instance names and parameters — good for bolts.

6Practice

  1. GA drawing of the gear reducer with an indented BOM and a separate parts-only purchase list on sheet 2.
  2. Add a MATERIAL column that reads &asm.mbr.PTC_MATERIAL_NAME.
  3. Balloon every item in the exploded view.
