SolidWorks Course Part II · Week 5 · Day 29

SolidWorks API and VBA Macros

Let SolidWorks do the boring clicks. Record, read and edit VBA macros that batch-export files and write properties through the SolidWorks API.

⏱ about 2–3 hours🧪 Lab: Macro generator❓ 5-question quiz

1Today's goals

  • Record, edit and run a macro
  • Read the API object chain: SldWorks → ModelDoc2 → Extension
  • Loop through a folder and export files
  • Write custom properties from code
  • Run macros safely

2What the API is

Everything you click in SolidWorks is also available to a program through the SolidWorks API. A macro is a small program inside SolidWorks: VBA (.swp, the most common), or VSTA in VB.NET/C#. Bigger tools become add-ins written in C# or VB.NET.

ObjectWhat it isTypical calls
SldWorksThe applicationActiveDoc, OpenDoc6, CloseDoc, GetExportFileData
ModelDoc2Any open documentGetTitle, GetPathName, ForceRebuild3, Save3
ModelDocExtensionMore document functionsSaveAs (export), CustomPropertyManager, SelectByID2
PartDoc / AssemblyDoc / DrawingDocType-specific functionsbodies, components, sheets and views
FeatureManagerCreates featuresextrudes, fillets, holes

Tools ▸ Macro ▸ Record writes code while you click — a great way to discover call names, though recorded code is long and full of exact pick points. Tools ▸ Macro ▸ New / Edit / Run. The API Help (Help ▸ API Help) lists every call with examples — it is the final authority.

Safety: a macro can overwrite or close files without asking. Test on a copy of the folder; keep backups; never run macros from unknown sources (they can do anything your Windows account can).

3Do it in SolidWorks

  1. Tools ▸ Macro ▸ Record. Change a dimension, rebuild, stop and save as rec1.swp. Open it with Edit and find your dimension value in the code.
  2. Tools ▸ Macro ▸ New → batch_step.swp. Paste the "Parts → STEP" macro from the lab and change the folder.
  3. Copy five parts into a test folder. In the VBA editor open View ▸ Immediate Window, then run with F5. Read the log lines.
  4. Set STEP options first: System Options ▸ Export ▸ STEP → AP214. The macro uses whatever is set there.
  5. Try the PDF macro on a folder of multi-sheet drawings and confirm every sheet is in the PDF.
  6. Try the custom property macro on an open part; check File ▸ Properties.
  7. Assign a macro to a toolbar button: Tools ▸ Customize ▸ Commands ▸ Macro → New Macro Button.

4Lab: macro generator

Choose a job, set the folder, and click each line of the generated code to see what it does. The code uses the standard SolidWorks API calls and the constants from the SolidWorks type libraries that new macros reference by default.

5Pro tips and common mistakes

  • Object variable not set — something returned Nothing (no document open, wrong document type, file failed to open). Check before using it.
  • Use Debug.Print and the Immediate window rather than many MsgBox lines.
  • Keep macros in a shared, version-controlled folder and put the standard header block at the top so you know what each one does.
  • Recorded selections (SelectByID2 with coordinates) break on other models — select by name instead.

6Practice

Write a macro that opens every drawing in a folder, exports a PDF and a DXF of sheet 1, and writes one line per file (name, OK/FAILED) into a text file using VBA Open … For Append.
