BALANCING PROCEDURE — SINGLE & DUAL PLANE (ISO 1940-1)
SINGLE PLANE METHOD
STEP 1 — WEIGH ALL BOLTS
Weigh each bolt individually. Record actual mass (nominal ±tolerance).

STEP 2 — SWAP-OPTIMIZE POSITIONS
For 8 bolts: exhaustive search through all 8! = 40,320 permutations finds the arrangement with minimum residual unbalance before any washers are added.

STEP 3 — COMPUTE STATIC UNBALANCE
Ux = Σ mᵢ·R·cos(θᵢ)
Uy = Σ mᵢ·R·sin(θᵢ)
U = √(Ux²+Uy²), φ = atan2(Uy,Ux)

STEP 4 — WASHER CORRECTION
Solver uses gradient-descent + integer coordinate-descent to find minimum washers. Places washers at bolts opposing the heavy spot vector.

STEP 5 — ISO 1940 VERIFICATION
e = G × 9549 / RPM (mm)
U_perm = e × M_rotor (g·mm)
DUAL PLANE METHOD
STEP 1 — SETUP GEOMETRY
Define planes at axial positions z1, z2. Define bearing positions a, b.

STEP 2 — SWAP-OPTIMIZE EACH PLANE
Each plane's 8 bolts are independently optimized — 8! search per plane. Total: 80,640 combinations evaluated.

STEP 3 — PLANE UNBALANCES
Each plane independently: compute Ux, Uy from bolt masses and angles.

STEP 4 — BEARING REACTIONS
FA = U1·(b-z1)/(b-a) + U2·(b-z2)/(b-a)
FB = U1·(z1-a)/(b-a) + U2·(z2-a)/(b-a)

STEP 5 — WASHER CORRECTION PER PLANE
Independent washer solver for each plane. Cross-plane coupling via influence coefficients.
⚠ WORST CASE — IMPROPER INSTALLATION EFFECTS
1. One bolt wrong position: Creates additional eccentricity ≈ m·2R·sin(θ_error/2)
2. Swapped adjacent bolts: Minimal if masses similar; serious if heavy bolt moved far.
3. All bolts identical except one heavy: Even +1g at R=50mm = 50 g·mm — may exceed G2.5 limit.
4. Tolerance stack alternating: Worst case alternating ±tol creates residual ≈ 2·tol·R·n/π
