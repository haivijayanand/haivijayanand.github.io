Open-source media: VLC, FFmpeg and friends

For Windows users in the 2000s, playing a video file often meant hunting for codec packs and fighting error messages. A student project in Paris changed that: VLC played almost anything, with nothing else to install, and never showed an advert. Behind it, and behind most of the world's video software, sits another open-source project — FFmpeg.

01The requirement: "this file cannot be played"

By the late 1990s video and music arrived on PCs in many formats — MPEG-1 on Video CDs (very common in India), MPEG-2 on DVDs, MP3 music, RealMedia streams, QuickTime movies, DivX and Xvid downloads, Windows Media files. Each needed its own codec (the program that compresses and decompresses the picture or sound), and each company's player supported mainly its own formats.

  • Windows Media Player relied on DirectShow codecs installed separately; a missing codec meant a black screen or "codec not found".
  • RealPlayer and QuickTime for Windows were large, pushed their own formats, nagged for upgrades and installed background services.
  • Users installed codec packs, which often conflicted with each other — "codec hell" — and fake codec downloads became a common way to spread malware.

02VLC: from a campus network to 7 billion downloads

In 1996 students at the École Centrale Paris wanted to stream satellite TV over their campus network. The project, VideoLAN, had a server and a client — the VideoLAN Client, or VLC. In February 2001 the school allowed the code to be released as open source under the GPL. The client soon became a stand-alone player for every platform: Windows, Linux, macOS, later Android and iOS.

The VideoLAN non-profit association, led for many years by Jean-Baptiste Kempf, keeps VLC free of adverts and tracking; the core libraries were moved to the more permissive LGPL in 2011 so other programs could embed them. Developers are paid through donations, sponsorships and consulting by companies built around VideoLAN.

The current stable release for Windows and macOS is VLC 3.0.23 (January 2026), still under the LGPLv2.1 licence. In August 2026 VideoLAN announced that VLC had passed 7 billion downloads, about 18 months after reaching 6 billion in January 2025. VLC 4 — a modernised interface and architecture — is still in development, without a release date.

In India, VideoLAN's website was blocked for most of 2022 and later unblocked. Throughout, the player itself kept working; the episode is a reminder to download only from the official site, videolan.org.

03See it: containers and codecs

A video file is a container (MP4, MKV, WebM, AVI) that holds separate streams — video, audio, subtitles — each compressed by its own codec. A player must understand the container and every codec inside. Choose a container and codecs to see whether they fit together.

04FFmpeg: the engine under almost everything

FFmpeg was started in 2000 by the French programmer Fabrice Bellard, who also wrote QEMU. Its libraries — libavcodec for codecs, libavformat for containers, libavfilter for effects — are used inside VLC, HandBrake, OBS Studio, Kodi, Audacity's import tools, web browsers, video sites and countless phones and cameras. In 2011 a group of developers forked it as Libav; most work later returned to FFmpeg and Libav faded. FFmpeg is LGPL (some optional parts GPL).

Try it: build an FFmpeg command

FFmpeg itself has no window — you type commands. This builder writes one for common jobs, such as shrinking a test-rig camera recording before attaching it to a report.

07Free, but not open source

  
Many popular Windows media programs cost nothing but keep their source code closed. That matters: you cannot inspect them, fix them or continue them if the owner stops, and the owner can change the terms.

09Installing safely

  
Fake download sites are the biggest risk with free software: search advertisements and look-alike domains offer "VLC" or "codec" installers bundled with adware or malware. Use the official site or Windows' own package manager, winget (built into Windows 10 and 11), which downloads from the publisher and checks the file hash.

  

    
ProgramOfficial sitewinget command

    
VLCvideolan.orgwinget install VideoLAN.VLC

Package identifiers occasionally change; winget search vlc lists the current one. winget upgrade --all updates every installed program in one step.






  
10Lessons for engineers

  
    
    
  1. Bundle what users need. VLC won by needing nothing else installed.
    2. 
    
  2. Separate the container from the content. Like a test-data file format that holds many channels, a media container must be read before its streams.
    3. 
    
  3. A shared engine multiplies impact. FFmpeg's libraries serve thousands of programs; one fix helps all of them.
    4. 
    
  4. Licences decide survival. Open-source players outlived their closed rivals because anyone could keep them going.
