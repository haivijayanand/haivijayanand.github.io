Mechanism: Connections, Gears and Motion

Mechanisms need parts that move the right way. Learn predefined connections (Pin, Slider, Cylinder, Planar, Ball, Bearing, Weld, 6DOF), the Mechanism application, gear pairs, servo motors and drag.

⏱ about 2–3 hours🧪 Lab: Connections + gear pair❓ 5-question quiz

1Today's goals

  • Use connections instead of constraints for moving parts
  • Know the DOF each connection leaves
  • Set joint axis zero and limits
  • Make a gear pair and a servo motor
  • Run a kinematic analysis and look for collisions

2Connections

In the Component Placement dashboard the list next to the constraint type has user-defined (ordinary constraints) and predefined connections. A connection is a constraint set that leaves exactly the motion you want, and Mechanism knows how to drive it.

Mechanism (Applications ▸ Mechanism) adds gear pairs, cams, belts, 3D contacts, springs, dampers, servo motors (prescribed motion on a connection axis) and analyses: Position (kinematics), Kinematic, Dynamic, Static, Force Balance.

Gear pair: the two gears each need a Pin connection; you give the pitch diameters and Creo applies the ratio N₂/N₁ = d₂/d₁.

3Do it in Creo

  1. Assembly gear_unit: housing placed with Default.
  2. Assemble the input shaft. In the dashboard choose Pin from the connection list. Axis alignment: shaft axis ↔ bore axis. Translation: shaft shoulder ↔ bearing face. Status: connection definition complete.
  3. Same for the output shaft (Pin). Model ▸ Drag Components (the hand icon) — drag a shaft: it only turns.
  4. Applications ▸ Mechanism ▸ Gears: Gear 1 = input pin, pitch Ø 34; Gear 2 = output pin, pitch Ø 84. OK.
  5. Servo Motor on the input pin: velocity 1450 rpm = 8700 deg/s.
  6. Mechanism Analysis ▸ Position, 1 s, 100 frames, motor on. Run. Play back with Playback; tick Global Interference to check collisions during motion.
  7. Add a slider: a piston with a Slider connection in a cylinder, and a Pin-connected con-rod — then drive the crank and watch the slider follow.

4Lab: connections and the gear pair

Pick a connection and press P to see the motion it allows.

Then size a gear pair: centre distance, ratio and the pitch diameters to enter in Mechanism.

5Pro tips and common mistakes

  • Use connections for anything that moves — constraints leave things free by accident; connections say what is free on purpose.
  • Set Zero and Limits on a Pin or Slider (Edit Definition ▸ Placement ▸ Rotation Axis) to stop drag going past real stops.
  • Gear pitch circles must touch: centre distance = (d₁ + d₂)/2. Check it in the skeleton, not by eye.
  • Kinematic analyses ignore mass; dynamic ones need mass properties (Day 14) and forces.
  • Save snapshots (Drag ▸ Snapshots) for positions you want on drawings: open, closed, mid-stroke.

6Practice

  1. Four-bar linkage: ground, crank 40, coupler 120, rocker 90, ground link 100. Pins at each joint, servo on the crank; plot the rocker angle.
  2. Slider-crank: crank 50, con-rod 180. Measure the piston stroke (should be 100) with a Measure of the slider position.
  3. The spur gear pair from the lab with 17 and 42 teeth, module 2: check centre distance 59 mm and the output speed.
